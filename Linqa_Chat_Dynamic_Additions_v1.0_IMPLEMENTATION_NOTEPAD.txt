LINQA CHAT — DYNAMIC ADDITIONS v1.0
Implementation pack for React Native / Expo
============================================================

PURPOSE
-------
Implements the approved dark Linqa Chats design additions:

1. Header calendar, call, search, and + controls.
2. Expandable + action hub: New chat, New group, Schedule,
   Start call, Broadcast, and Scan QR.
3. Upcoming scheduled-call card with Join.
4. Dynamic presence/status carousel.
5. All / Unread / Groups / Pinned filters.
6. Deduplicated chat list with typing, voice note, missed call,
   mute, pin, encryption, read receipt, and unread indicators.
7. Persistent bottom navigation.

IMPORTANT PRODUCTION RULES
--------------------------
- Never render PostgreSQL, server version, environment, host, or other
  developer diagnostics in this consumer screen.
- The client must not claim "End-to-end encrypted" unless the conversation
  has a server-authoritative E2EE capability and a valid local session.
- Call joining, scheduling, unread counts, presence, and typing state must
  come from authenticated services. Do not generate fake success states.
- Deduplicate conversations by conversationId, never by display name.
- Route every mutation through the existing authenticated API client.

import type { ChatInboxPayload, ChatFilter } from './types';

export interface AuthenticatedHttpClient {
  get<T>(path: string, options?: { signal?: AbortSignal }): Promise<T>;
  post<T>(path: string, body?: unknown): Promise<T>;
}

export class ChatApi {
  constructor(private readonly http: AuthenticatedHttpClient) {}

  inbox(filter: ChatFilter, signal?: AbortSignal): Promise<ChatInboxPayload> {
    return this.http.get<ChatInboxPayload>(
      `/v1/chats/inbox?filter=${encodeURIComponent(filter)}`,
      { signal },
    );
  }

  createDirect(userId: string): Promise<{ conversationId: string }> {
    return this.http.post('/v1/chats/direct', { userId });
  }

  joinScheduledCall(eventId: string): Promise<{ callId: string; joinToken: string }> {
    return this.http.post(`/v1/calls/scheduled/${encodeURIComponent(eventId)}/join`);
  }

  markRead(conversationId: string): Promise<void> {
    return this.http.post(`/v1/chats/${encodeURIComponent(conversationId)}/read`);
  }
}

import { useCallback, useEffect, useMemo, useRef, useState } from 'react';
import type { ChatApi } from './chatApi';
import type { ChatFilter, ChatInboxPayload, ChatSummary } from './types';

const EMPTY: ChatInboxPayload = {
  unreadTotal: 0,
  scheduledCall: null,
  presence: [],
  conversations: [],
};

function deduplicate(items: ChatSummary[]): ChatSummary[] {
  const byId = new Map<string, ChatSummary>();
  for (const item of items) {
    const current = byId.get(item.conversationId);
    if (!current || Date.parse(item.updatedAt) > Date.parse(current.updatedAt)) {
      byId.set(item.conversationId, item);
    }
  }
  return [...byId.values()].sort((a, b) => {
    if (a.pinned !== b.pinned) return a.pinned ? -1 : 1;
    return Date.parse(b.updatedAt) - Date.parse(a.updatedAt);
  });
}

export function useChatInbox(api: ChatApi, filter: ChatFilter) {
  const [data, setData] = useState(EMPTY);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  const mounted = useRef(true);

  const refresh = useCallback(async (signal?: AbortSignal) => {
    setError(null);
    try {
      const result = await api.inbox(filter, signal);
      if (!mounted.current) return;
      setData({ ...result, conversations: deduplicate(result.conversations) });
    } catch (cause) {
      if (signal?.aborted || !mounted.current) return;
      setError(cause instanceof Error ? cause.message : 'Unable to load chats');
    } finally {
      if (mounted.current && !signal?.aborted) setLoading(false);
    }
  }, [api, filter]);

  useEffect(() => {
    mounted.current = true;
    const controller = new AbortController();
    setLoading(true);
    void refresh(controller.signal);
    return () => {
      mounted.current = false;
      controller.abort();
    };
  }, [refresh]);

  const counts = useMemo(() => ({
    all: data.conversations.length,
    unread: data.conversations.filter(x => x.unreadCount > 0).length,
    groups: data.conversations.filter(x => x.isGroup).length,
    pinned: data.conversations.filter(x => x.pinned).length,
  }), [data.conversations]);

  return { data, counts, loading, error, refresh };
}

function timeLabel(value: string): string {
  const date = new Date(value);
  const diff = Date.now() - date.getTime();
  if (diff < 60_000) return 'now';
  if (diff < 3_600_000) return `${Math.floor(diff / 60_000)}m`;
  if (diff < 86_400_000) return `${Math.floor(diff / 3_600_000)}h`;
  return date.toLocaleDateString(undefined, { weekday: 'short' });
}

FILE 5: SERVER CONTRACTS / ROUTES TO CONNECT
============================================================

GET /v1/chats/inbox?filter=all|unread|groups|pinned
Response: ChatInboxPayload. The server must:
- authenticate the installation/session;
- authorize every returned conversation membership;
- aggregate unread counts server-side;
- return only verified E2EE status;
- paginate in production (cursor + limit);
- redact blocked users and deleted messages;
- never return plaintext message bodies unavailable to this device.

POST /v1/chats/direct { userId }
- resolve or atomically create one direct conversation;
- enforce blocks, privacy/discovery rules, and abuse limits;
- return the stable conversationId.

POST /v1/calls/scheduled/:eventId/join
- verify invitation, time window, device trust, and call permissions;
- mint a short-lived, audience-bound join token;
- never expose provider credentials to the client.

WebSocket topics:
- chat.inbox.updated
- chat.typing.updated
- presence.updated
- call.schedule.updated

Apply received events by conversationId/userId and trigger a throttled refresh.
Presence and typing events must expire; do not persist them as permanent state.
