
================================================================================
LINQASEND™ — TRANSFER CLASSIFICATION + COUNTRY CAPABILITY ENGINE v3
Production-Safe Revision
Format: Notepad-friendly TXT
Targets:
- TypeScript / Node.js / NestJS- or Express-compatible backend
- PostgreSQL
- Redis
- Existing Linqa auth / device trust / risk / KYC
- Existing LinqaSend internal + external transfer modules

THIS v3 REPLACES THE v2 EXECUTION MODEL WHILE PRESERVING THE FOUR-CLASS MODEL:

1. INTERNAL_DOMESTIC
2. INTERNAL_CROSS_BORDER
3. EXTERNAL_DOMESTIC
4. EXTERNAL_CROSS_BORDER

CRITICAL DESIGN CHANGES IN v3
- Server derives sender country/account/KYC/risk context.
- Client cannot submit authoritative sender eligibility fields.
- TransferClass is separate from FundingMode and ReceiveMode.
- INTERNAL_DOMESTIC no longer automatically means INTERNAL_LEDGER.
- Same-country / different-currency is explicitly governed.
- FX uses market reference rate + provider execution rate + Linqa customer rate.
- FX math avoids binary floating-point settlement arithmetic.
- Quotes are persisted and immutable after creation.
- Country/corridor capability rules are effective-dated and versioned.
- Every transfer stores a capability + policy snapshot.
- RESTRICTED / RECEIVE_ONLY / SUSPENDED fail closed.
- Create -> review -> warnings -> step-up authorization -> confirm -> execute.
- Idempotency is mandatory.
- Ledger is immutable; balance projection is updated atomically with journal entries.
- INTERNAL_CROSS_BORDER has a dedicated router.
- Request Money resolves both users server-side.
- Send Back creates a fresh draft; it never executes automatically.
- Recipient resolution is typed.
- Transfer state machine is expanded for production operations.

05. CLASSIFICATION
================================================================================

export interface TransferClassification {
  transferClass: TransferClass;
  sameCountry: boolean;
  sameCurrency: boolean;
  internalRecipient: boolean;
}

export class TransferClassifier {
  classify(
    sender: SenderContext,
    recipient: ResolvedRecipient,
  ): TransferClassification {
    const sameCountry =
      sender.verifiedCountry.toUpperCase() ===
      recipient.verifiedCountry.toUpperCase();

    const sameCurrency =
      sender.baseCurrency.toUpperCase() ===
      recipient.receiveCurrency.toUpperCase();

    const internalRecipient =
      recipient.recipientType === RecipientType.LINQA_USER;

    if (internalRecipient && sameCountry) {
      return {
        transferClass: TransferClass.INTERNAL_DOMESTIC,
        sameCountry,
        sameCurrency,
        internalRecipient,
      };
    }

    if (internalRecipient && !sameCountry) {
      return {
        transferClass: TransferClass.INTERNAL_CROSS_BORDER,
        sameCountry,
        sameCurrency,
        internalRecipient,
      };
    }

    if (!internalRecipient && sameCountry) {
      return {
        transferClass: TransferClass.EXTERNAL_DOMESTIC,
        sameCountry,
        sameCurrency,
        internalRecipient,
      };
    }

    return {
      transferClass: TransferClass.EXTERNAL_CROSS_BORDER,
      sameCountry,
      sameCurrency,
      internalRecipient,
    };
  }
}

07. REGULATORY CAPABILITY ENGINE v3
================================================================================

export class RegulatoryCapabilityEngine {
  constructor(
    private readonly repo: CapabilityRepository,
  ) {}

  async decide(args: {
    sender: SenderContext;
    recipient: ResolvedRecipient;
    classification: TransferClassification;

    amount: Money;

    fundingMode: FundingMode;
    receiveMode: ReceiveMode;

    purposeCode?: string;
  }): Promise<CapabilityDecision> {
    const now = new Date();

    const source =
      args.sender.verifiedCountry.toUpperCase();

    const destination =
      args.recipient.verifiedCountry.toUpperCase();

    if (args.sender.accountStatus !== "ACTIVE") {
      return this.block(
        args.classification.transferClass,
        "SENDER_ACCOUNT_NOT_ACTIVE",
      );
    }

    // INTERNAL_DOMESTIC is special because cross-border outbound status
    // must never automatically block valid domestic use.
    if (
      args.classification.transferClass ===
      TransferClass.INTERNAL_DOMESTIC
    ) {
      const country =
        await this.repo.getActiveCountryVersion(
          source,
          now,
        );

      if (!country) {
        return this.block(
          TransferClass.INTERNAL_DOMESTIC,
          "COUNTRY_CAPABILITY_NOT_CONFIGURED",
        );
      }

      switch (country.domesticInternalStatus) {
        case CapabilityStatus.ENABLED:
        case CapabilityStatus.CONDITIONAL:
          break;

        case CapabilityStatus.RECEIVE_ONLY:
        case CapabilityStatus.BANK_OUTBOUND_ONLY:
        case CapabilityStatus.RESTRICTED:
        case CapabilityStatus.TEMPORARILY_SUSPENDED:
        case CapabilityStatus.UNSUPPORTED:
        default:
          return {
            ...this.block(
              TransferClass.INTERNAL_DOMESTIC,
              "DOMESTIC_INTERNAL_NOT_AVAILABLE",
            ),
            status:
              country.domesticInternalStatus,
            countryPolicyId:
              country.id,
            countryPolicyVersion:
              country.version,
          };
      }

      if (
        !country.allowedFundingModes.includes(
          args.fundingMode,
        )
      ) {
        return this.blockWithPolicy(
          TransferClass.INTERNAL_DOMESTIC,
          country,
          "DOMESTIC_FUNDING_MODE_NOT_ALLOWED",
        );
      }

      if (
        !country.allowedReceiveModes.includes(
          args.receiveMode,
        )
      ) {
        return this.blockWithPolicy(
          TransferClass.INTERNAL_DOMESTIC,
          country,
          "DOMESTIC_RECEIVE_MODE_NOT_ALLOWED",
        );
      }

      // Same country but different currency is NOT automatically approved.
      // It requires a configured corridor-like domestic FX rule.
      if (!args.classification.sameCurrency) {
        const domesticFxRule =
          await this.repo.getActiveCorridorVersion(
            source,
            destination,
            TransferClass.INTERNAL_DOMESTIC,
            now,
          );

        if (!domesticFxRule) {
          return this.blockWithPolicy(
            TransferClass.INTERNAL_DOMESTIC,
            country,
            "DOMESTIC_INTERNAL_FX_NOT_CONFIGURED",
          );
        }

        return this.evaluateRule({
          sender: args.sender,
          recipient: args.recipient,
          classification: args.classification,
          amount: args.amount,
          fundingMode: args.fundingMode,
          receiveMode: args.receiveMode,
          purposeCode: args.purposeCode,
          country,
          rule: domesticFxRule,
        });
      }

      // Pure balance-to-balance same-currency domestic transfer.
      if (
        args.fundingMode ===
          FundingMode.LINQA_BALANCE &&
        args.receiveMode ===
          ReceiveMode.LINQA_BALANCE
      ) {
        return {
          allowed: true,
          status:
            country.domesticInternalStatus,
          transferClass:
            TransferClass.INTERNAL_DOMESTIC,
          requiresFx: false,
          requiresBankRail: false,
          permittedRails: [
            RailType.INTERNAL_LEDGER,
          ],
          permittedFundingModes:
            country.allowedFundingModes,
          permittedReceiveModes:
            country.allowedReceiveModes,
          countryPolicyId: country.id,
          countryPolicyVersion:
            country.version,
        };
      }

      // Domestic Linqa-to-Linqa but externally funded / externally received.
      return {
        allowed: true,
        status:
          country.domesticInternalStatus,
        transferClass:
          TransferClass.INTERNAL_DOMESTIC,
        requiresFx: false,
        requiresBankRail:
          args.fundingMode ===
            FundingMode.BANK ||
          args.receiveMode ===
            ReceiveMode.BANK,
        permittedRails: [
          RailType.DOMESTIC_FUNDING,
          RailType.LOCAL_BANK,
          RailType.MOBILE_MONEY,
          RailType.CARD_PUSH,
        ],
        permittedFundingModes:
          country.allowedFundingModes,
        permittedReceiveModes:
          country.allowedReceiveModes,
        countryPolicyId: country.id,
        countryPolicyVersion:
          country.version,
      };
    }

    // All non-domestic-internal transfers require an effective-dated corridor.
    const rule =
      await this.repo.getActiveCorridorVersion(
        source,
        destination,
        args.classification.transferClass,
        now,
      );

    if (!rule) {
      return this.block(
        args.classification.transferClass,
        "CORRIDOR_NOT_CONFIGURED",
      );
    }

    return this.evaluateRule({
      sender: args.sender,
      recipient: args.recipient,
      classification: args.classification,
      amount: args.amount,
      fundingMode: args.fundingMode,
      receiveMode: args.receiveMode,
      purposeCode: args.purposeCode,
      rule,
    });
  }

  private evaluateRule(args: {
    sender: SenderContext;
    recipient: ResolvedRecipient;
    classification: TransferClassification;
    amount: Money;
    fundingMode: FundingMode;
    receiveMode: ReceiveMode;
    purposeCode?: string;

    country?: CountryCapabilityVersion;
    rule: CorridorRuleVersion;
  }): CapabilityDecision {
    const { rule } = args;

    switch (rule.status) {
      case CapabilityStatus.ENABLED:
      case CapabilityStatus.CONDITIONAL:
        break;

      case CapabilityStatus.BANK_OUTBOUND_ONLY:
        break;

      case CapabilityStatus.RECEIVE_ONLY:
        return this.ruleBlocked(
          args,
          "OUTBOUND_NOT_ALLOWED_RECEIVE_ONLY",
        );

      case CapabilityStatus.RESTRICTED:
        return this.ruleBlocked(
          args,
          "CORRIDOR_RESTRICTED",
        );

      case CapabilityStatus.TEMPORARILY_SUSPENDED:
        return this.ruleBlocked(
          args,
          "CORRIDOR_TEMPORARILY_SUSPENDED",
        );

      case CapabilityStatus.UNSUPPORTED:
      default:
        return this.ruleBlocked(
          args,
          "CORRIDOR_UNSUPPORTED",
        );
    }

    if (
      rule.minAmountMinor !== undefined &&
      args.amount.amountMinor <
        rule.minAmountMinor
    ) {
      return this.ruleBlocked(
        args,
        "CORRIDOR_MINIMUM_NOT_MET",
      );
    }

    if (
      rule.maxAmountMinor !== undefined &&
      args.amount.amountMinor >
        rule.maxAmountMinor
    ) {
      return this.ruleBlocked(
        args,
        "CORRIDOR_LIMIT_EXCEEDED",
      );
    }

    if (
      rule.minKycLevel !== undefined &&
      args.sender.kycLevel <
        rule.minKycLevel
    ) {
      return this.ruleBlocked(
        args,
        "KYC_LEVEL_INSUFFICIENT",
      );
    }

    if (
      !rule.sourceCurrencies.includes(
        args.amount.currency.toUpperCase(),
      )
    ) {
      return this.ruleBlocked(
        args,
        "SOURCE_CURRENCY_UNSUPPORTED",
      );
    }

    if (
      !rule.destinationCurrencies.includes(
        args.recipient.receiveCurrency.toUpperCase(),
      )
    ) {
      return this.ruleBlocked(
        args,
        "DESTINATION_CURRENCY_UNSUPPORTED",
      );
    }

    if (
      !rule.permittedFundingModes.includes(
        args.fundingMode,
      )
    ) {
      return this.ruleBlocked(
        args,
        "FUNDING_MODE_NOT_ALLOWED",
      );
    }

    if (
      !rule.permittedReceiveModes.includes(
        args.receiveMode,
      )
    ) {
      return this.ruleBlocked(
        args,
        "RECEIVE_MODE_NOT_ALLOWED",
      );
    }

    if (
      rule.requiresPurposeCode &&
      !args.purposeCode
    ) {
      return this.ruleBlocked(
        args,
        "PURPOSE_CODE_REQUIRED",
      );
    }

    const requiresBankRail =
      rule.status ===
      CapabilityStatus.BANK_OUTBOUND_ONLY;

    const rails =
      requiresBankRail
        ? rule.permittedRails.filter(
            (rail) =>
              rail ===
                RailType.LOCAL_BANK ||
              rail ===
                RailType.CORRESPONDENT_BANK,
          )
        : rule.permittedRails;

    if (rails.length === 0) {
      return this.ruleBlocked(
        args,
        "NO_PERMITTED_RAIL",
      );
    }

    return {
      allowed: true,
      status: rule.status,
      transferClass:
        args.classification.transferClass,
      requiresFx:
        !args.classification.sameCurrency,
      requiresBankRail,
      permittedRails: rails,
      permittedFundingModes:
        rule.permittedFundingModes,
      permittedReceiveModes:
        rule.permittedReceiveModes,
      countryPolicyId:
        args.country?.id,
      countryPolicyVersion:
        args.country?.version,
      corridorRuleId: rule.id,
      corridorRuleVersion:
        rule.version,
    };
  }

  private block(
    transferClass: TransferClass,
    reasonCode: string,
  ): CapabilityDecision {
    return {
      allowed: false,
      status:
        CapabilityStatus.UNSUPPORTED,
      reasonCode,
      transferClass,
      requiresFx: false,
      requiresBankRail: false,
      permittedRails: [],
      permittedFundingModes: [],
      permittedReceiveModes: [],
    };
  }

  private blockWithPolicy(
    transferClass: TransferClass,
    country: CountryCapabilityVersion,
    reasonCode: string,
  ): CapabilityDecision {
    return {
      ...this.block(
        transferClass,
        reasonCode,
      ),
      status:
        country.domesticInternalStatus,
      countryPolicyId:
        country.id,
      countryPolicyVersion:
        country.version,
    };
  }

  private ruleBlocked(
    args: {
      classification: TransferClassification;
      country?: CountryCapabilityVersion;
      rule: CorridorRuleVersion;
    },
    reasonCode: string,
  ): CapabilityDecision {
    return {
      allowed: false,
      status:
        args.rule.status,
      reasonCode,
      transferClass:
        args.classification.transferClass,
      requiresFx:
        !args.classification.sameCurrency,
      requiresBankRail:
        args.rule.status ===
        CapabilityStatus.BANK_OUTBOUND_ONLY,
      permittedRails:
        args.rule.permittedRails,
      permittedFundingModes:
        args.rule.permittedFundingModes,
      permittedReceiveModes:
        args.rule.permittedReceiveModes,
      countryPolicyId:
        args.country?.id,
      countryPolicyVersion:
        args.country?.version,
      corridorRuleId:
        args.rule.id,
      corridorRuleVersion:
        args.rule.version,
    };
  }
}

export interface CapabilitySnapshot {
  evaluatedAt: string;

  transferClass: TransferClass;

  sourceCountry: string;
  destinationCountry: string;

  capabilityStatus:
    CapabilityStatus;

  countryPolicyId?: string;
  countryPolicyVersion?: number;

  corridorRuleId?: string;
  corridorRuleVersion?: number;

  fundingMode: FundingMode;
  receiveMode: ReceiveMode;

  permittedRails: RailType[];

  requiresFx: boolean;
  requiresBankRail: boolean;
}

export function makeCapabilitySnapshot(
  sender: SenderContext,
  recipient: ResolvedRecipient,
  fundingMode: FundingMode,
  receiveMode: ReceiveMode,
  decision: CapabilityDecision,
): CapabilitySnapshot {
  return {
    evaluatedAt:
      new Date().toISOString(),

    transferClass:
      decision.transferClass,

    sourceCountry:
      sender.verifiedCountry,

    destinationCountry:
      recipient.verifiedCountry,

    capabilityStatus:
      decision.status,

    countryPolicyId:
      decision.countryPolicyId,

    countryPolicyVersion:
      decision.countryPolicyVersion,

    corridorRuleId:
      decision.corridorRuleId,

    corridorRuleVersion:
      decision.corridorRuleVersion,

    fundingMode,
    receiveMode,

    permittedRails:
      decision.permittedRails,

    requiresFx:
      decision.requiresFx,

    requiresBankRail:
      decision.requiresBankRail,
  };
}

export class RecipientResolver {

  async resolve(
    ref: RecipientReference,
  ): Promise<ResolvedRecipient> {
    switch (ref.type) {
      case RecipientType.LINQA_USER: {
        const user =
          await this.repo.findLinqaUserByReference(
            ref.value,
          );

        if (!user) {
          throw new Error(
            "LINQA_RECIPIENT_NOT_FOUND",
          );
        }

        return {
          recipientType:
            RecipientType.LINQA_USER,
          recipientId:
            user.userId,
          userId:
            user.userId,
          customerLedgerAccountId:
            user.customerLedgerAccountId,
          verifiedCountry:
            user.verifiedCountry,
          receiveCurrency:
            user.receiveCurrency,
          receiveMode:
            user.receiveMode,
          verified: true,
        };
      }

      case RecipientType.BANK_RECIPIENT: {
        const item =
          await this.repo.findBankRecipientByToken(
            ref.token,
          );

        if (!item) {
          throw new Error(
            "BANK_RECIPIENT_NOT_FOUND",
          );
        }

        return {
          recipientType:
            RecipientType.BANK_RECIPIENT,
          recipientId:
            item.recipientId,
          verifiedCountry:
            item.verifiedCountry,
          receiveCurrency:
            item.receiveCurrency,
          receiveMode:
            ReceiveMode.BANK,
          bankRecipientToken:
            item.bankRecipientToken,
          verified: true,
        };
      }

      case RecipientType.MOBILE_MONEY_RECIPIENT: {
        const item =
          await this.repo.findMobileRecipientByToken(
            ref.token,
          );

        if (!item) {
          throw new Error(
            "MOBILE_RECIPIENT_NOT_FOUND",
          );
        }

        return {
          recipientType:
            RecipientType.MOBILE_MONEY_RECIPIENT,
          recipientId:
            item.recipientId,
          verifiedCountry:
            item.verifiedCountry,
          receiveCurrency:
            item.receiveCurrency,
          receiveMode:
            ReceiveMode.MOBILE_MONEY,
          mobileMoneyToken:
            item.mobileMoneyToken,
          verified: true,
        };
      }

      case RecipientType.CARD_RECIPIENT: {
        const item =
          await this.repo.findCardRecipientByToken(
            ref.token,
          );

        if (!item) {
          throw new Error(
            "CARD_RECIPIENT_NOT_FOUND",
          );
        }

        return {
          recipientType:
            RecipientType.CARD_RECIPIENT,
          recipientId:
            item.recipientId,
          verifiedCountry:
            item.verifiedCountry,
          receiveCurrency:
            item.receiveCurrency,
          receiveMode:
            ReceiveMode.CARD,
          cardRecipientToken:
            item.cardRecipientToken,
          verified: true,
        };
      }
    }
  }

export class FxPricingEngine {
  constructor(
    private readonly rates:
      FxRateProviderV3,
    private readonly pricing:
      FxPricingRepositoryV3,
    private readonly decimals:
      DecimalMath,
    private readonly quotes:
      QuoteRepositoryV3,
  ) {}

  async createQuote(args: {
    sender: SenderContext;
    recipient: ResolvedRecipient;

    classification:
      TransferClassification;

    capability:
      CapabilityDecision;

    capabilitySnapshot:
      CapabilitySnapshot;

    amount: Money;

    rail: RailType;
  }): Promise<PersistedQuote> {
    const sameCurrency =
      args.amount.currency.toUpperCase() ===
      args.recipient.receiveCurrency.toUpperCase();

    if (sameCurrency) {
      return this.quotes.insert({
        senderUserId:
          args.sender.userId,
        recipientId:
          args.recipient.recipientId,

        transferClass:
          args.classification.transferClass,

        sourceCountry:
          args.sender.verifiedCountry,
        destinationCountry:
          args.recipient.verifiedCountry,

        sourceAmountMinor:
          args.amount.amountMinor,
        sourceCurrency:
          args.amount.currency.toUpperCase(),

        destinationAmountMinor:
          args.amount.amountMinor,
        destinationCurrency:
          args.recipient.receiveCurrency.toUpperCase(),

        senderFeeMinor: 0n,
        recipientFeeMinor: 0n,

        customerRate: "1.000000000000",

        capabilitySnapshot:
          args.capabilitySnapshot,

        pricingSnapshot: {
          customerRate:
            "1.000000000000",
          marginBps: 0,
        },

        rail: args.rail,

        expiresAt:
          new Date(
            Date.now() + 60_000,
          ),
      });
    }

    const market =
      await this.rates.getRate({
        sourceCurrency:
          args.amount.currency,
        destinationCurrency:
          args.recipient.receiveCurrency,
      });

    const rule =
      await this.pricing.getActiveRule({
        sourceCountry:
          args.sender.verifiedCountry,
        destinationCountry:
          args.recipient.verifiedCountry,
        sourceCurrency:
          args.amount.currency,
        destinationCurrency:
          args.recipient.receiveCurrency,
      });

    if (!rule) {
      throw new Error(
        "FX_PRICING_RULE_NOT_CONFIGURED",
      );
    }

    const rawBps =
      rule.baseMarginBps +
      rule.volatilityBufferBps +
      rule.liquidityBufferBps +
      rule.settlementBufferBps -
      rule.promotionAdjustmentBps;

    const marginBps =
      Math.max(
        rule.minMarginBps,
        Math.min(
          rule.maxMarginBps,
          rawBps,
        ),
      );

    const customerRate =
      this.decimals.applyBps(
        market.providerExecutionRate,
        -marginBps,
      );

    const destinationAmountMinor =
      this.decimals.multiplyMinorByRate(
        args.amount.amountMinor,
        customerRate,
      );

    return this.quotes.insert({
      senderUserId:
        args.sender.userId,
      recipientId:
        args.recipient.recipientId,

      transferClass:
        args.classification.transferClass,

      sourceCountry:
        args.sender.verifiedCountry,
      destinationCountry:
        args.recipient.verifiedCountry,

      sourceAmountMinor:
        args.amount.amountMinor,
      sourceCurrency:
        args.amount.currency.toUpperCase(),

      destinationAmountMinor,
      destinationCurrency:
        args.recipient.receiveCurrency.toUpperCase(),

      senderFeeMinor: 0n,
      recipientFeeMinor: 0n,

      customerRate,

      capabilitySnapshot:
        args.capabilitySnapshot,

      pricingSnapshot: {
        pricingRuleId:
          rule.id,
        pricingRuleVersion:
          rule.version,

        marketReferenceRate:
          market.marketReferenceRate,
        providerExecutionRate:
          market.providerExecutionRate,
        customerRate,

        marginBps,

        provider:
          market.provider,

        sourceTimestamp:
          market.sourceTimestamp.toISOString(),
      },

      rail: args.rail,

      expiresAt:
        new Date(
          Math.min(
            market.expiresAt.getTime(),
            Date.now() + 30_000,
          ),
        ),
    });
  }
}

export interface RiskDecisionV3 {

    | "ALLOW"

    | "STEP_UP"
    | "REVIEW"
    | "HOLD"
    | "DECLINE";

export interface RiskSignalRepositoryV3 {
  collect(args: {
    senderUserId: string;
    recipientId: string;
    sourceCountry: string;
    destinationCountry: string;
    amountMinor: bigint;
    currency: string;
    transferClass: TransferClass;
  }): Promise<{
    firstRecipientPayment: boolean;
    priorSuccessfulTransfers: number;
    relationshipAgeDays: number;
    recentPasswordReset: boolean;
    recentRecoveryChange: boolean;
    recentDeviceChange: boolean;
    trustedDevice: boolean;
    transferVelocity24h: number;
    amountDeviationRatio: number;
    countryAnomaly: boolean;
  }>;
}

export class InternalAndCrossBorderRiskEngine {
  assess(
    s: Awaited<
      ReturnType<
        RiskSignalRepositoryV3["collect"]
      >
    >,
  ): RiskDecisionV3 {
    let score = 0;
    const reasons: string[] = [];

    const add = (
      condition: boolean,
      points: number,
      reason: string,
    ) => {
      if (condition) {
        score += points;
        reasons.push(reason);
      }
    };

    add(
      s.firstRecipientPayment,
      15,
      "FIRST_PAYMENT_TO_RECIPIENT",
    );

    add(
      s.recentPasswordReset,
      20,
      "RECENT_PASSWORD_RESET",
    );

    add(
      s.recentRecoveryChange,
      20,
      "RECENT_RECOVERY_CHANGE",
    );

    add(
      s.recentDeviceChange,
      20,
      "RECENT_DEVICE_CHANGE",
    );

    add(
      !s.trustedDevice,
      15,
      "UNTRUSTED_DEVICE",
    );

    add(
      s.transferVelocity24h >= 5,
      15,
      "HIGH_TRANSFER_VELOCITY",
    );

    add(
      s.amountDeviationRatio >= 3,
      20,
      "AMOUNT_OUTSIDE_NORMAL_PATTERN",
    );

    add(
      s.countryAnomaly,
      15,
      "COUNTRY_ANOMALY",
    );

    add(
      s.priorSuccessfulTransfers === 0 &&
        s.relationshipAgeDays < 1,
      15,
      "NO_ESTABLISHED_RELATIONSHIP",
    );

    if (score >= 85) {
      return {
        decision: "DECLINE",
        score,
        reasons,
      };
    }

    if (score >= 65) {
      return {
        decision: "HOLD",
        score,
        reasons,
      };
    }

    if (score >= 45) {
      return {
        decision: "REVIEW",
        score,
        reasons,
      };
    }

    if (score >= 25) {
      return {
        decision: "WARN",
        score,
        reasons,
      };
    }

    if (score >= 10) {
      return {
        decision: "STEP_UP",
        score,
        reasons,
      };
    }

    return {
      decision: "ALLOW",
      score,
      reasons,
    };
  }
}

export class ScamWarningEngineV3 {
  build(args: {
    risk:
      RiskDecisionV3;
    amountMinor: bigint;
    currency: string;
  }) {
    const warnings: Array<{
      type: string;
      severity:
        | "INFO"
        | "WARN"
        | "HIGH";
      messageKey: string;
    }> = [];

    if (
      args.risk.reasons.includes(
        "FIRST_PAYMENT_TO_RECIPIENT",
      )
    ) {
      warnings.push({
        type: "NEW_RECIPIENT",
        severity: "WARN",
        messageKey:
          "linqasend.scam.new_recipient",
      });
    }

    if (
      args.risk.reasons.includes(
        "RECENT_DEVICE_CHANGE",
      ) ||
      args.risk.reasons.includes(
        "RECENT_PASSWORD_RESET",
      ) ||
      args.risk.reasons.includes(
        "RECENT_RECOVERY_CHANGE",
      )
    ) {
      warnings.push({
        type:
          "SECURITY_CHANGE_PROXIMITY",
        severity: "HIGH",
        messageKey:
          "linqasend.scam.security_change",
      });
    }

    return warnings;
  }
}

    fundingMode:
      FundingMode;
    receiveMode:
      ReceiveMode;
  }): Promise<RailType> {

        TransferClass.INTERNAL_DOMESTIC &&
      args.classification.sameCurrency &&
      args.fundingMode ===
        FundingMode.LINQA_BALANCE &&
      args.receiveMode ===

        !args.capability.permittedRails.includes(
          RailType.INTERNAL_LEDGER,
        )
      ) {
        throw new Error(
          "INTERNAL_LEDGER_NOT_PERMITTED",
        );
      }

      return RailType.INTERNAL_LEDGER;
    }

    const candidates =
      args.capability.requiresBankRail
        ? args.capability.permittedRails.filter(
            (x) =>
              x ===
                RailType.LOCAL_BANK ||
              x ===
                RailType.CORRESPONDENT_BANK,
          )
        : args.capability.permittedRails;

    for (const rail of candidates) {
      if (
        await this.health.isHealthy(
          rail,
        )
      ) {
        return rail;
      }
    }

    throw new Error(
      "NO_HEALTHY_PERMITTED_RAIL",
    );
  }
}

export interface TransferAuthorizationClaims {
  sub: string;

  transferId: string;
  recipientId: string;

  quoteId: string;

  sourceAmountMinor: string;
  sourceCurrency: string;

  jti: string;
  exp: number;
}

export class TransferAuthorizationServiceV3 {
  constructor(
    private readonly signer:
      TransactionTokenSigner,
    private readonly redis:
      RedisService,
  ) {}

  async issue(args: {
    senderUserId: string;
    transferId: string;
    recipientId: string;
    quoteId: string;
    sourceAmountMinor: bigint;
    sourceCurrency: string;
  }) {
    const jti =
      crypto.randomUUID();

    await this.redis.set(
      `linqasend:v3:auth:${jti}`,
      "ACTIVE",
      120,
    );

    return this.signer.sign({
      sub:
        args.senderUserId,
      transferId:
        args.transferId,
      recipientId:
        args.recipientId,
      quoteId:
        args.quoteId,
      sourceAmountMinor:
        args.sourceAmountMinor.toString(),
      sourceCurrency:
        args.sourceCurrency,
      jti,
      exp:
        Math.floor(
          Date.now() / 1000,
        ) + 120,
    });
  }

  async consume(
    token: string,
    expected: Omit<
      TransferAuthorizationClaims,
      "jti" | "exp"
    >,
  ) {
    const claims =
      await this.signer.verify(
        token,
      );

    if (
      claims.sub !== expected.sub ||
      claims.transferId !==
        expected.transferId ||
      claims.recipientId !==
        expected.recipientId ||
      claims.quoteId !==
        expected.quoteId ||
      claims.sourceAmountMinor !==
        expected.sourceAmountMinor ||
      claims.sourceCurrency !==
        expected.sourceCurrency
    ) {
      throw new Error(
        "TRANSFER_AUTHORIZATION_MISMATCH",
      );
    }

    // Must be atomic: Redis GETDEL or Lua.
    const state =
      await this.redis.getDel(
        `linqasend:v3:auth:${claims.jti}`,
      );

    if (state !== "ACTIVE") {
      throw new Error(
        "TRANSFER_AUTHORIZATION_USED_OR_EXPIRED",
      );
    }

    return claims;
  }
}

export interface LedgerRepositoryV3 {
  withTransaction<T>(
    fn: (
      tx: unknown,
    ) => Promise<T>,
  ): Promise<T>;

  createJournal(
    tx: unknown,
    input: {
      referenceType: string;
      referenceId: string;
      description: string;
      reversalOf?: string;
    },
  ): Promise<{
    id: string;
  }>;

  insertPosting(
    tx: unknown,
    input: {
      journalId: string;
      accountId: string;
      direction:
        | "DEBIT"
        | "CREDIT";
      amountMinor: bigint;
      currency: string;
    },
  ): Promise<void>;

  // Projection update is only permitted inside same DB transaction as journal.
  updateBalanceProjection(
    tx: unknown,
    input: {
      accountId: string;
      deltaMinor: bigint;
    },
  ): Promise<void>;

  lockBalanceProjection(
    tx: unknown,
    accountId: string,
  ): Promise<{
    availableMinor: bigint;
    currency: string;
  }>;
}

export class DoubleEntryLedgerV3 {
  constructor(
    private readonly repo:
      LedgerRepositoryV3,
  ) {}

  private assertBalanced(
    postings: LedgerPosting[],
  ) {
    const currencies =
      new Set(
        postings.map(
          (p) => p.currency,
        ),
      );

    for (const currency of currencies) {
      const scoped =
        postings.filter(
          (p) =>
            p.currency ===
            currency,
        );

      const debits =
        scoped
          .filter(
            (p) =>
              p.direction ===
              "DEBIT",
          )
          .reduce(
            (sum, p) =>
              sum +
              p.amountMinor,
            0n,
          );

      const credits =
        scoped
          .filter(
            (p) =>
              p.direction ===
              "CREDIT",
          )
          .reduce(
            (sum, p) =>
              sum +
              p.amountMinor,
            0n,
          );

      if (debits !== credits) {
        throw new Error(
          `UNBALANCED_LEDGER_${currency}`,
        );
      }
    }
  }

  async postDomesticBalanceTransfer(args: {
    transferId: string;

    senderLiabilityAccountId: string;
    recipientLiabilityAccountId: string;

    amountMinor: bigint;
    currency: string;
  }) {
    if (
      args.senderLiabilityAccountId ===
      args.recipientLiabilityAccountId
    ) {
      throw new Error(
        "SELF_TRANSFER_NOT_ALLOWED",
      );
    }

    const postings: LedgerPosting[] = [
      {
        accountId:
          args.senderLiabilityAccountId,
        direction: "DEBIT",
        amountMinor:
          args.amountMinor,
        currency:
          args.currency,
      },
      {
        accountId:
          args.recipientLiabilityAccountId,
        direction: "CREDIT",
        amountMinor:
          args.amountMinor,
        currency:
          args.currency,
      },
    ];

    this.assertBalanced(postings);

    await this.repo.withTransaction(
      async (tx) => {
        const senderProjection =
          await this.repo.lockBalanceProjection(
            tx,
            args.senderLiabilityAccountId,
          );

        if (
          senderProjection.currency !==
          args.currency
        ) {
          throw new Error(
            "SENDER_LEDGER_CURRENCY_MISMATCH",
          );
        }

        if (
          senderProjection.availableMinor <
          args.amountMinor
        ) {
          throw new Error(
            "INSUFFICIENT_FUNDS",
          );
        }

        const journal =
          await this.repo.createJournal(
            tx,
            {
              referenceType:
                "LINQASEND_TRANSFER",
              referenceId:
                args.transferId,
              description:
                "Internal domestic balance transfer",
            },
          );

        for (const p of postings) {
          await this.repo.insertPosting(
            tx,
            {
              journalId:
                journal.id,
              ...p,
            },
          );
        }

        await this.repo.updateBalanceProjection(
          tx,
          {
            accountId:
              args.senderLiabilityAccountId,
            deltaMinor:
              -args.amountMinor,
          },
        );

        await this.repo.updateBalanceProjection(
          tx,
          {
            accountId:
              args.recipientLiabilityAccountId,
            deltaMinor:
              args.amountMinor,
          },
        );
      },
    );
  }
}

export interface TransferExecutionContext {

    context:
      TransferExecutionContext,
  ): Promise<{
    status: TransferState;
    providerReference?: string;
  }>;
}

export class InternalDomesticRouter
  implements TransferClassRouter
{
  constructor(
    private readonly ledger:
      DoubleEntryLedgerV3,
    private readonly externalFunding:
      DomesticFundingExecutor,
    private readonly recipientCredit:
      DomesticRecipientCreditService,
  ) {}

  async execute(
    ctx: TransferExecutionContext,
  ) {
    const pureBalance =
      ctx.fundingSource.mode ===
        FundingMode.LINQA_BALANCE &&
      ctx.recipient.receiveMode ===
        ReceiveMode.LINQA_BALANCE &&
      ctx.quote.sourceCurrency ===
        ctx.quote.destinationCurrency;

    if (pureBalance) {
      if (
        !ctx.sender.customerLedgerAccountId ||
        !ctx.recipient.customerLedgerAccountId
      ) {
        throw new Error(
          "CUSTOMER_LEDGER_ACCOUNT_MISSING",
        );
      }

      await this.ledger.postDomesticBalanceTransfer({
        transferId:
          ctx.transferId,
        senderLiabilityAccountId:
          ctx.sender.customerLedgerAccountId,
        recipientLiabilityAccountId:
          ctx.recipient.customerLedgerAccountId,
        amountMinor:
          ctx.quote.sourceAmountMinor,
        currency:
          ctx.quote.sourceCurrency,
      });

      return {
        status:
          TransferState.COMPLETED,
      };
    }

    const funding =
      await this.externalFunding.authorizeAndSettle({
        transferId:
          ctx.transferId,
        sender:
          ctx.sender,
        fundingSource:
          ctx.fundingSource,
        quote:
          ctx.quote,
      });

    const credit =
      await this.recipientCredit.credit({

      providerReference:
        credit.reference ??
        funding.reference,
    };
  }

export class LinqaSendPrepareServiceV3 {
  constructor(
    private readonly senderContexts:
      SenderContextService,
    private readonly recipients:
      RecipientResolver,
    private readonly fundingSources:
      FundingSourceService,
    private readonly classifier:
      TransferClassifier,
    private readonly capabilities:
      RegulatoryCapabilityEngine,
    private readonly rails:
      RailRouterV3,
    private readonly fx:
      FxPricingEngine,
  ) {}

  async prepare(args: {
    authenticatedUserId: string;

    request:
      CreateTransferIntentRequest;
  }) {
    const sender =
      await this.senderContexts.resolveFromAuthenticatedUser(
        args.authenticatedUserId,
      );

    const recipient =
      await this.recipients.resolve(
        args.request.recipient,
      );

    if (
      recipient.userId ===
      sender.userId
    ) {
      throw new Error(
        "SELF_TRANSFER_NOT_ALLOWED",
      );
    }

    const fundingSource =
      await this.fundingSources.resolveOwnedActive(
        sender.userId,
        args.request.fundingSourceId,
      );

    const classification =
      this.classifier.classify(
        sender,
        recipient,
      );

    const amount: Money = {
      amountMinor:
        BigInt(
          args.request.amountMinor,
        ),
      currency:
        args.request.currency.toUpperCase(),
    };

    const capability =
      await this.capabilities.decide({
        sender,
        recipient,
        classification,
        amount,
        fundingMode:
          fundingSource.mode,
        receiveMode:
          recipient.receiveMode,
        purposeCode:
          args.request.purposeCode,
      });

    if (!capability.allowed) {
      throw new Error(
        capability.reasonCode ??
          "CAPABILITY_BLOCKED",
      );
    }

    const capabilitySnapshot =
      makeCapabilitySnapshot(
        sender,
        recipient,
        fundingSource.mode,
        recipient.receiveMode,
        capability,
      );

    const rail =
      await this.rails.select({
        classification,
        capability,
        fundingMode:
          fundingSource.mode,
        receiveMode:
          recipient.receiveMode,
      });

    const quote =
      await this.fx.createQuote({
        sender,
        recipient,
        classification,
        capability,
        capabilitySnapshot,
        amount,
        rail,
      });

    return {
      sender: {
        userId:
          sender.userId,
        verifiedCountry:
          sender.verifiedCountry,
        baseCurrency:
          sender.baseCurrency,
      },

      recipient: {
        recipientId:
          recipient.recipientId,
        recipientType:
          recipient.recipientType,
        verifiedCountry:
          recipient.verifiedCountry,
        receiveCurrency:
          recipient.receiveCurrency,
        receiveMode:
          recipient.receiveMode,
      },

      classification,
      capability:
        capabilitySnapshot,
      fundingMode:
        fundingSource.mode,
      rail,
      quote,
    };
  }
}

export class LinqaSendCreateTransferServiceV3 {
  constructor(
    private readonly prepareService:
      LinqaSendPrepareServiceV3,
    private readonly transfers:
      TransferRepositoryV3,
    private readonly riskSignals:
      RiskSignalRepositoryV3,
    private readonly risk:
      InternalAndCrossBorderRiskEngine,
    private readonly scam:
      ScamWarningEngineV3,
  ) {}

  async create(args: {
    authenticatedUserId: string;

    request:
      CreateTransferIntentRequest;

    idempotencyKey: string;
  }) {
    const existing =
      await this.transfers.findByIdempotency({
        senderUserId:
          args.authenticatedUserId,
        idempotencyKey:
          args.idempotencyKey,
      });

    if (existing) {
      return existing;
    }

    const prepared =
      await this.prepareService.prepare({
        authenticatedUserId:
          args.authenticatedUserId,
        request:
          args.request,
      });

    const transfer =
      await this.transfers.create({
        senderUserId:
          prepared.sender.userId,
        recipientId:
          prepared.recipient.recipientId,
        transferClass:
          prepared.classification.transferClass,
        sourceCountry:
          prepared.sender.verifiedCountry,
        destinationCountry:
          prepared.recipient.verifiedCountry,
        fundingSourceId:
          args.request.fundingSourceId,
        fundingMode:
          prepared.fundingMode,
        receiveMode:
          prepared.recipient.receiveMode,
        quoteId:
          prepared.quote.id,
        state:
          TransferState.AWAITING_CONFIRMATION,
        capabilitySnapshot:
          prepared.capability,
        regulatoryPolicyVersion:
          this.policyVersionLabel(
            prepared.capability,
          ),
        idempotencyKey:
          args.idempotencyKey,
      });

    const signals =
      await this.riskSignals.collect({
        senderUserId:
          prepared.sender.userId,
        recipientId:
          prepared.recipient.recipientId,
        sourceCountry:
          prepared.sender.verifiedCountry,
        destinationCountry:
          prepared.recipient.verifiedCountry,
        amountMinor:
          prepared.quote.sourceAmountMinor,
        currency:
          prepared.quote.sourceCurrency,
        transferClass:
          prepared.classification.transferClass,
      });

    const risk =
      this.risk.assess(
        signals,
      );

    if (
      risk.decision === "DECLINE"
    ) {
      await this.transfers.updateState(
        transfer.id,
        TransferState.DECLINED,
        { risk },
      );

      return this.transfers.findOwned(
        prepared.sender.userId,
        transfer.id,
      );
    }

    if (
      risk.decision === "HOLD"
    ) {
      await this.transfers.updateState(
        transfer.id,
        TransferState.ON_HOLD,
        { risk },
      );

      return this.transfers.findOwned(
        prepared.sender.userId,
        transfer.id,
      );
    }

    if (
      risk.decision === "REVIEW"
    ) {
      await this.transfers.updateState(
        transfer.id,
        TransferState.MANUAL_REVIEW,
        { risk },
      );

      return this.transfers.findOwned(
        prepared.sender.userId,
        transfer.id,
      );
    }

    const warnings =
      this.scam.build({
        risk,
        amountMinor:
          prepared.quote.sourceAmountMinor,
        currency:
          prepared.quote.sourceCurrency,
      });

    if (warnings.length > 0) {
      await this.transfers.updateState(
        transfer.id,
        TransferState.SCAM_WARNING_REQUIRED,
        {
          warnings,
          risk,
        },
      );
    }

    return this.transfers.findOwned(
      prepared.sender.userId,
      transfer.id,
    );
  }

  private policyVersionLabel(
    snapshot:
      CapabilitySnapshot,
  ) {
    return [
      snapshot.countryPolicyId ??
        "none",
      snapshot.countryPolicyVersion ??
        "none",
      snapshot.corridorRuleId ??
        "none",
      snapshot.corridorRuleVersion ??
        "none",
    ].join(":");
  }
}

export class LinqaSendConfirmServiceV3 {
  constructor(
    private readonly transfers:
      TransferRepositoryV3,
    private readonly quotes:
      QuoteRepositoryV3,
    private readonly senderContexts:
      SenderContextService,
    private readonly recipients:
      RecipientRepositoryForExecution,
    private readonly fundingSources:
      FundingSourceService,
    private readonly authz:
      TransferAuthorizationServiceV3,
    private readonly routers:
      TransferClassRouterRegistry,
  ) {}

  async issueAuthorization(args: {
    authenticatedUserId: string;
    transferId: string;
  }) {
    const transfer =
      await this.transfers.findOwned(
        args.authenticatedUserId,
        args.transferId,
      );

    if (!transfer) {
      throw new Error(
        "TRANSFER_NOT_FOUND",
      );
    }

    if (
      transfer.state !==
      TransferState.AWAITING_CONFIRMATION
    ) {
      throw new Error(
        "TRANSFER_NOT_READY_FOR_AUTHORIZATION",
      );
    }

    const quote =
      await this.quotes.findValidOwned({
        quoteId:
          transfer.quoteId,
        senderUserId:
          transfer.senderUserId,
        now:
          new Date(),
      });

    if (!quote) {
      await this.transfers.updateState(
        transfer.id,
        TransferState.EXPIRED,
      );

      throw new Error(
        "QUOTE_EXPIRED",
      );
    }

    await this.transfers.updateState(
      transfer.id,
      TransferState.AUTHENTICATING,
    );

    return this.authz.issue({
      senderUserId:
        transfer.senderUserId,
      transferId:
        transfer.id,
      recipientId:
        transfer.recipientId,
      quoteId:
        quote.id,
      sourceAmountMinor:
        quote.sourceAmountMinor,
      sourceCurrency:
        quote.sourceCurrency,
    });
  }

  async confirm(args: {
    authenticatedUserId: string;
    transferId: string;
    authorizationToken: string;
  }) {
    const transfer =
      await this.transfers.findOwned(
        args.authenticatedUserId,
        args.transferId,
      );

    if (!transfer) {
      throw new Error(
        "TRANSFER_NOT_FOUND",
      );
    }

    const quote =
      await this.quotes.findValidOwned({
        quoteId:
          transfer.quoteId,
        senderUserId:
          transfer.senderUserId,
        now:
          new Date(),
      });

    if (!quote) {
      await this.transfers.updateState(
        transfer.id,
        TransferState.EXPIRED,
      );

      throw new Error(
        "QUOTE_EXPIRED",
      );
    }

    await this.authz.consume(
      args.authorizationToken,
      {
        sub:
          transfer.senderUserId,
        transferId:
          transfer.id,
        recipientId:
          transfer.recipientId,
        quoteId:
          quote.id,
        sourceAmountMinor:
          quote.sourceAmountMinor.toString(),
        sourceCurrency:
          quote.sourceCurrency,
      },
    );

    await this.transfers.updateState(
      transfer.id,
      TransferState.AUTHORIZED,
    );

    const sender =
      await this.senderContexts.resolveFromAuthenticatedUser(
        transfer.senderUserId,
      );

    const recipient =
      await this.recipients.resolveForExecution(
        transfer.recipientId,
        transfer.receiveMode,
      );

    const fundingSource =
      await this.fundingSources.resolveOwnedActive(
        transfer.senderUserId,
        transfer.fundingSourceId,
      );

    const router =
      this.routers.get(
        transfer.transferClass,
      );

    const result =
      await router.execute({
        transferId:
          transfer.id,
        sender,
        recipient,
        quote,
        fundingSource,
        capabilitySnapshot:
          transfer.capabilitySnapshot,
      });

    await this.transfers.updateState(
      transfer.id,
      result.status,
      {
        providerReference:
          result.providerReference,
      },
    );

    return {
      transferId:
        transfer.id,
      state:
        result.status,
    };
  }
}

export interface RequestMoneyRepositoryV3 {
  create(input: {
    requesterUserId: string;
    payerUserId: string;

    sourceCountry: string;
    payerCountry: string;

    amountMinor: bigint;
    currency: string;

    note?: string;

    status: "PENDING";

    expiresAt: Date;
  }): Promise<{
    id: string;
  }>;
}

export class RequestMoneyServiceV3 {
  constructor(
    private readonly senderContexts:
      SenderContextService,
    private readonly userResolver:
      InternalUserResolver,
    private readonly capabilities:
      CapabilityRepository,
    private readonly permissions:
      PaymentRequestPermissionService,
    private readonly blocks:
      UserBlockService,
    private readonly requests:
      RequestMoneyRepositoryV3,
  ) {}

  async create(args: {
    authenticatedUserId: string;
    payerReference: string;
    amountMinor: string;
    currency: string;
    note?: string;
  }) {
    const requester =
      await this.senderContexts.resolveFromAuthenticatedUser(
        args.authenticatedUserId,
      );

    const payer =
      await this.userResolver.resolveVerifiedUser(
        args.payerReference,
      );

    if (
      requester.userId ===
      payer.userId
    ) {
      throw new Error(
        "CANNOT_REQUEST_FROM_SELF",
      );
    }

    if (
      await this.blocks.isBlockedEitherDirection(
        requester.userId,
        payer.userId,
      )
    ) {
      throw new Error(
        "REQUEST_NOT_ALLOWED",
      );
    }

    await this.permissions.assertCanRequest({
      requesterUserId:
        requester.userId,
      payerUserId:
        payer.userId,
    });

    const sameCountry =
      requester.verifiedCountry ===
      payer.verifiedCountry;

    if (sameCountry) {
      const country =
        await this.capabilities.getActiveCountryVersion(
          requester.verifiedCountry,
          new Date(),
        );

      if (
        !country ||
        ![
          CapabilityStatus.ENABLED,
          CapabilityStatus.CONDITIONAL,
        ].includes(
          country.domesticRequestMoneyStatus,
        )
      ) {
        throw new Error(
          "DOMESTIC_REQUEST_MONEY_DISABLED",
        );
      }
    }

    return this.requests.create({
      requesterUserId:
        requester.userId,
      payerUserId:
        payer.userId,
      sourceCountry:
        requester.verifiedCountry,
      payerCountry:
        payer.verifiedCountry,
      amountMinor:
        BigInt(
          args.amountMinor,
        ),
      currency:
        args.currency.toUpperCase(),
      note:
        args.note,
      status:
        "PENDING",
      expiresAt:
        new Date(
          Date.now() +
          7 * 24 * 60 * 60 * 1000,
        ),
    });
  }
}

34. TEST MATRIX v3
================================================================================

CLASSIFICATION
- NG Linqa -> NG Linqa => INTERNAL_DOMESTIC
- NG Linqa -> US Linqa => INTERNAL_CROSS_BORDER
- NG Linqa -> NG bank => EXTERNAL_DOMESTIC
- NG Linqa -> US bank => EXTERNAL_CROSS_BORDER
- internal cross-border never downgraded

TRUST BOUNDARY
- client-supplied country ignored/rejected
- client-supplied KYC ignored/rejected
- client-supplied risk score ignored/rejected
- sender account derived from authenticated user
- recipient country derived from server recipient record

CAPABILITY
- missing country config => UNSUPPORTED
- missing corridor => UNSUPPORTED
- RECEIVE_ONLY outbound => blocked
- RESTRICTED => blocked
- TEMPORARILY_SUSPENDED => blocked
- BANK_OUTBOUND_ONLY filters rails
- funding mode rejected when not permitted
- receive mode rejected when not permitted
- effective-dated policy selection
- historical policy remains queryable

DOMESTIC INTERNAL
- same currency balance->balance => INTERNAL_LEDGER
- debit card->Linqa balance => no pure INTERNAL_LEDGER shortcut
- bank->Linqa balance => domestic funding route
- same country/different currency without rule => blocked
- same country/different currency with rule => FX route

FX
- rate uses exact decimal arithmetic
- no Number(bigint) conversion
- market rate stored
- provider execution rate stored
- customer rate stored
- margin bps stored
- sender fee = 0
- recipient fee = 0
- quote immutable
- quote expiry enforced

AUTHORIZATION
- transfer cannot execute from create request
- authorization challenge required
- token bound to sender/transfer/recipient/quote/amount/currency
- token expires
- token replay rejected

IDEMPOTENCY
- duplicate create returns original transfer
- duplicate confirm does not double debit
- duplicate external payout prevented
- duplicate reversal prevented

LEDGER
- postings immutable
- per-currency debits equal credits
- sender customer liability debit
- recipient customer liability credit
- balance projection updated in same transaction
- projection cannot diverge from journal in successful commit
- reversal creates reversing journal

REQUEST MONEY
- payer resolved server-side
- requester resolved from auth
- block/privacy permissions checked
- domestic request capability checked
- request never auto-debits payer

SEND BACK
- returns draft only
- original sender becomes new recipient
- new quote required
- new capability check required
- new auth required

CHAT
- chat intent derives recipient from conversation membership
- chat never receives payout token
- chat never receives bank/card data
- chat never receives risk score/AML result

FAILURE
- quote expires after transfer created
- provider outage
- Redis outage
- DB outage
- ledger failure
- recipient credit failure
- reconciliation mismatch
- worker replay
- duplicate provider webhook

36. NON-NEGOTIABLE SECURITY INVARIANTS
================================================================================

1. INTERNAL_DOMESTIC requires:
   sender verified country == recipient verified country
   AND recipient is a verified Linqa user.

2. INTERNAL_CROSS_BORDER can NEVER be reclassified as INTERNAL_DOMESTIC.

3. Linqa membership can NEVER bypass:
   - sanctions
   - AML/CFT
   - capital controls
   - FX restrictions
   - outbound remittance restrictions
   - KYC/KYB requirements
   - local stored-value/payment licensing

4. Client cannot determine:
   - regulatory eligibility
   - sender country
   - recipient country
   - KYC level
   - risk score
   - transfer class
   - rail
   - FX rate
   - receive amount
   - completion status

5. Missing policy config fails closed.

6. Every quote is persisted.

7. Every transfer stores the policy/capability snapshot that authorized it.

8. Pure internal ledger routing is permitted only for eligible domestic balance-to-balance transfers.

9. Same-country different-currency transfers require explicit domestic FX capability.

10. All money-moving mutation endpoints require idempotency.

11. Every completed transfer is backed by server-authoritative ledger/settlement evidence.

12. Chat/social never receives payment secrets.

13. Send Back never executes automatically.

14. Request Money never debits automatically.

15. Ledger corrections are reversing entries, never destructive edits.
