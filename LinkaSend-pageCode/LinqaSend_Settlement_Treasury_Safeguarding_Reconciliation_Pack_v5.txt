POSITION IN ARCHITECTURE
--------------------------------------------------------------------------------
Authenticated User
  -> Transfer Classification + Country Capability Engine v3
  -> Transaction Security & Fraud Defense v4
  -> Funding Authorization
  -> Transfer-Class Router
  -> Immutable Ledger
  -> Recipient Credit
  -> [ v5 SETTLEMENT / TREASURY / SAFEGUARDING / RECONCILIATION ]
  -> Finality / Exception Handling
  -> Server-Authoritative Completion

PRIMARY DOMAINS
--------------------------------------------------------------------------------
1. Safeguarded customer-funds accounts
2. Customer-liability accounting
3. Settlement-account registry
4. Treasury positions by currency
5. FX liquidity and corridor liquidity
6. Provider receivables/payables
7. Bank/provider settlement instructions
8. Settlement batches
9. Reconciliation
10. Reconciliation breaks
11. Suspense accounts
12. Fees / FX margin / revenue recognition
13. Refunds and reversals
14. Chargebacks
15. Reserve / prefunding monitoring
16. Treasury limits and alerts
17. Maker-checker for treasury operations
18. End-of-day controls
19. Operational evidence
20. Admin / Money Operations dashboard
21. Automated workers
22. Test matrix

NON-NEGOTIABLE PRINCIPLES
--------------------------------------------------------------------------------
- Customer funds and Linqa operating funds must be separately accounted for.
- Customer liability totals must reconcile to safeguarded/settlement assets as
  required by the deployment's regulated operating model.
- Do not treat "internal balance" as free money. It is a customer liability.
- Ledger journals are immutable.
- Corrections use reversals and correcting journals.
- Reconciliation breaks never disappear through destructive edits.
- Provider reports are external evidence, not the system of record.
- Linqa ledger is internally authoritative, but must reconcile to bank/provider
  settlement evidence.
- Completion and settlement are distinct states.

import { Injectable } from "@nestjs/common";

@Injectable()
export class SettlementAccountService {
  constructor(
    private readonly repo: SettlementAccountRepository,
  ) {}

  async requireActive(args: {
    accountCode: string;
    currency: string;
  }) {
    const account =
      await this.repo.findByCode(
        args.accountCode,
      );

    if (!account) {
      throw new Error(
        "SETTLEMENT_ACCOUNT_NOT_FOUND",
      );
    }

    if (
      account.status !==
      "ACTIVE"
    ) {
      throw new Error(
        "SETTLEMENT_ACCOUNT_NOT_ACTIVE",
      );
    }

    if (
      account.currency !==
      args.currency
    ) {
      throw new Error(
        "SETTLEMENT_ACCOUNT_CURRENCY_MISMATCH",
      );
    }

    return account;
  }
}

@Injectable()
export class CustomerLiabilityService {
  constructor(
    private readonly ledger:
      LedgerAggregateRepository,
  ) {}

  async getTotal(
    currency: string,
  ): Promise<bigint> {
    return this.ledger.sumByAccountClass({
      accountClass:
        "LIABILITY",
      ownerType:
        "USER",
      currency,
    });
  }

  async getUserLiability(
    userId: string,
    currency: string,
  ) {
    return this.ledger.getUserBalance({
      userId,
      currency,
    });
  }
}

import { Injectable } from "@nestjs/common";

@Injectable()
export class SafeguardingAccountService {
  constructor(
    private readonly settlementAccounts:
      SettlementAccountRepository,

    private readonly externalBalances:
      ExternalAccountBalanceProvider,

    private readonly liabilities:
      CustomerLiabilityService,
  ) {}

  async checkCurrency(
    currency: string,
  ): Promise<SafeguardingCheckResult> {
    const accounts =
      await this.settlementAccounts.listActive({
        accountType:
          "SAFEGUARDING",
        currency,
      });

    let asset = 0n;

    for (const account of accounts) {
      const balance =
        await this.externalBalances.getBalance(
          account,
        );

      asset +=
        balance.availableMinor;
    }

    const liability =
      await this.liabilities.getTotal(
        currency,
      );

    const delta =
      asset - liability;

    return {
      currency,
      customerLiabilityMinor:
        liability,
      safeguardingAssetMinor:
        asset,
      deltaMinor:
        delta,
      status:
        delta === 0n
          ? "BALANCED"
          : delta < 0n
            ? "ASSET_SHORTFALL"
            : "ASSET_EXCESS",
    };
  }
}

import { Injectable } from "@nestjs/common";

@Injectable()
export class TreasuryPositionService {
  constructor(
    private readonly liabilities:
      CustomerLiabilityService,

    private readonly accounts:
      TreasuryAccountAggregationRepository,

    private readonly repo:
      TreasuryPositionRepository,
  ) {}

  async calculate(
    currency: string,
    positionDate = new Date(),
  ): Promise<CurrencyPosition> {
    const [
      customerLiabilityMinor,
      safeguardingAssetMinor,
      providerReceivableMinor,
      providerPayableMinor,
      fxLiquidityMinor,
      reserveMinor,
      suspense,
    ] = await Promise.all([
      this.liabilities.getTotal(
        currency,
      ),

      this.accounts.sumExternalType(
        "SAFEGUARDING",
        currency,
      ),

      this.accounts.sumProviderReceivables(
        currency,
      ),

      this.accounts.sumProviderPayables(
        currency,
      ),

      this.accounts.sumExternalType(
        "FX_LIQUIDITY",
        currency,
      ),

      this.accounts.sumExternalType(
        "RESERVE",
        currency,
      ),

      this.accounts.sumSuspense(
        currency,
      ),
    ]);

    const availableLiquidityMinor =
      safeguardingAssetMinor +
      fxLiquidityMinor +
      providerReceivableMinor -
      providerPayableMinor -
      customerLiabilityMinor;

    const position = {
      currency,

      safeguardingAssetMinor,
      customerLiabilityMinor,

      providerReceivableMinor,
      providerPayableMinor,

      fxLiquidityMinor,
      reserveMinor,

      suspenseDebitMinor:
        suspense.debitMinor,

      suspenseCreditMinor:
        suspense.creditMinor,

      availableLiquidityMinor,
    };

    await this.repo.upsert({
      positionDate,
      ...position,
    });

    return position;
  }
}

import { Injectable } from "@nestjs/common";

@Injectable()
export class LiquidityPolicyService {
  constructor(
    private readonly repo:
      LiquidityPolicyRepository,
  ) {}

  async evaluate(args: {
    country?: string;
    currency: string;
    availableMinor: bigint;
  }) {
    const policy =
      await this.repo.getActive(
        args.country,
        args.currency,
        new Date(),
      );

    if (!policy) {
      return {
        state: "NO_POLICY",
        allowNewTransfers: false,
      };
    }

    if (
      args.availableMinor <
      policy.minAvailableMinor
    ) {
      return {
        state: "CRITICAL",
        allowNewTransfers: false,
        requiredTopUpMinor:
          policy.targetAvailableMinor -
          args.availableMinor,
      };
    }

    if (
      args.availableMinor <
      policy.targetAvailableMinor
    ) {
      return {
        state: "WARNING",
        allowNewTransfers: true,
        requiredTopUpMinor:
          policy.targetAvailableMinor -
          args.availableMinor,
      };
    }

    if (
      args.availableMinor >
      policy.maxAvailableMinor
    ) {
      return {
        state: "EXCESS",
        allowNewTransfers: true,
        excessMinor:
          args.availableMinor -
          policy.targetAvailableMinor,
      };
    }

    return {
      state: "HEALTHY",
      allowNewTransfers: true,
    };
  }
}

import {
  createHash,
} from "crypto";
import {
  Injectable,
} from "@nestjs/common";

@Injectable()
export class SettlementBatchService {
  constructor(
    private readonly batches:
      SettlementBatchRepository,

    private readonly instructions:
      SettlementInstructionRepository,
  ) {}

  async build(args: {
    providerId: string;
    currency: string;
    settlementDate: string;
    batchType: string;
  }) {
    const batch =
      await this.batches.getOrCreate({
        ...args,
        status: "OPEN",
      });

    const candidates =
      await this.instructions.listEligibleForBatch({
        providerId:
          args.providerId,
        currency:
          args.currency,
        batchType:
          args.batchType,
      });

    let total = 0n;

    for (const item of candidates) {
      await this.batches.addItem(
        batch.id,
        item.id,
        item.amountMinor,
      );

      total +=
        item.amountMinor;
    }

    const checksum =
      createHash("sha256")
        .update(
          candidates
            .map(
              (x) =>
                `${x.id}|${x.amountMinor}|${x.currency}`,
            )
            .sort()
            .join("\n"),
        )
        .digest("hex");

    return this.batches.seal({
      batchId:
        batch.id,
      instructionCount:
        candidates.length,
      totalAmountMinor:
        total,
      checksum,
    });
  }
}

import { Injectable } from "@nestjs/common";

@Injectable()
export class ReconciliationService {
  constructor(
    private readonly external:
      ExternalSettlementRecordRepository,

    private readonly internal:
      ReconciliationInternalRepository,

    private readonly runs:
      ReconciliationRunRepository,

    private readonly matches:
      ReconciliationMatchRepository,

    private readonly breaks:
      ReconciliationBreakService,
  ) {}

  async reconcileProvider(args: {
    providerId: string;
    currency: string;

    periodStart: Date;
    periodEnd: Date;
  }) {
    const run =
      await this.runs.create({
        runType:
          "PROVIDER",
        providerId:
          args.providerId,
        currency:
          args.currency,
        periodStart:
          args.periodStart,
        periodEnd:
          args.periodEnd,
        status:
          "RUNNING",
      });

    const internalRows =
      await this.internal.listProviderSettlementRows(
        args,
      );

    const externalRows =
      await this.external.listProviderRows(
        args,
      );

    const externalByReference =
      new Map(
        externalRows.map(
          (r) => [
            r.externalRecordId,
            r,
          ],
        ),
      );

    let matched = 0;
    let breakCount = 0;

    for (const internalRow of internalRows) {
      const externalRow =
        externalByReference.get(
          internalRow.providerReference,
        );

      if (!externalRow) {
        const match =
          await this.matches.create({
            runId:
              run.id,
            internalReferenceType:
              internalRow.referenceType,
            internalReferenceId:
              internalRow.referenceId,
            status:
              "MISSING_EXTERNAL",
            internalAmountMinor:
              internalRow.amountMinor,
            externalAmountMinor:
              null,
            currency:
              internalRow.currency,
            deltaMinor:
              internalRow.amountMinor,
            matchMethod:
              "PROVIDER_REFERENCE",
          });

        await this.breaks.openFromMatch(
          run.id,
          match,
        );

        breakCount++;
        continue;
      }

      const delta =
        externalRow.amountMinor -
        internalRow.amountMinor;

      const status =
        delta === 0n
          ? "MATCHED"
          : "MISMATCH";

      const match =
        await this.matches.create({
          runId:
            run.id,
          internalReferenceType:
            internalRow.referenceType,
          internalReferenceId:
            internalRow.referenceId,
          externalRecordId:
            externalRow.id,
          status,
          internalAmountMinor:
            internalRow.amountMinor,
          externalAmountMinor:
            externalRow.amountMinor,
          currency:
            internalRow.currency,
          deltaMinor:
            delta,
          matchMethod:
            "PROVIDER_REFERENCE",
        });

      if (
        status ===
        "MATCHED"
      ) {
        matched++;
      } else {
        await this.breaks.openFromMatch(
          run.id,
          match,
        );
        breakCount++;
      }

      externalByReference.delete(
        internalRow.providerReference,
      );
    }

    for (const extra of externalByReference.values()) {
      const match =
        await this.matches.create({
          runId:
            run.id,
          internalReferenceType:
            "UNKNOWN",
          internalReferenceId:
            "NONE",
          externalRecordId:
            extra.id,
          status:
            "MISSING_INTERNAL",
          internalAmountMinor:
            null,
          externalAmountMinor:
            extra.amountMinor,
          currency:
            extra.currency,
          deltaMinor:
            extra.amountMinor,
          matchMethod:
            "UNMATCHED_EXTERNAL",
        });

      await this.breaks.openFromMatch(
        run.id,
        match,
      );

      breakCount++;
    }

    return this.runs.complete({
      runId:
        run.id,
      matchedCount:
        matched,
      breakCount,
      status:
        breakCount > 0
          ? "COMPLETED_WITH_BREAKS"
          : "COMPLETED",
    });
  }
}

import { Injectable } from "@nestjs/common";

@Injectable()
export class ReconciliationBreakService {
  constructor(
    private readonly repo:
      ReconciliationBreakRepository,

    private readonly suspense:
      SuspenseAccountService,
  ) {}

  async openFromMatch(
    runId: string,
    match: ReconciliationMatch,
  ) {
    const severity =
      classifyBreakSeverity(
        match.deltaMinor ?? 0n,
      );

    const item =
      await this.repo.create({
        runId,
        matchId:
          match.id,
        breakType:
          match.status,
        severity,
        currency:
          match.currency,
        amountMinor:
          absBigInt(
            match.deltaMinor ?? 0n,
          ),
        status:
          "OPEN",
        details: {
          internalReference:
            match.internalReferenceId,
          externalRecord:
            match.externalRecordId,
        },
      });

    if (
      match.status ===
        "MISSING_INTERNAL" ||
      match.status ===
        "MISMATCH"
    ) {
      await this.suspense.openForBreak(
        item,
      );
    }

    return item;
  }
}

function absBigInt(
  value: bigint,
) {
  return value < 0n
    ? -value
    : value;
}

function classifyBreakSeverity(
  delta: bigint,
): BreakSeverity {
  const abs =
    absBigInt(delta);

  if (abs === 0n)
    return "LOW";

  if (abs < 10_000n)
    return "LOW";

  if (abs < 100_000n)
    return "MEDIUM";

  if (abs < 1_000_000n)
    return "HIGH";

  return "CRITICAL";
}

import {

} from "crypto";
import {
  Injectable,

@Injectable()
export class EndOfDayControlService {

      TreasuryPositionService,

      ReconciliationBreakRepository,

    private readonly suspense:

    private readonly repo:

  ) {}

  async run(
    controlDate: Date,
    currency: string,
  ) {
    const [
      safeguard,
      treasury,
      openBreaks,
      criticalBreaks,
      openSuspense,
      openFx,
    ] = await Promise.all([
      this.safeguarding.checkCurrency(
        currency,
      ),

      this.treasury.calculate(
        currency,
        controlDate,
      ),

      this.breaks.countOpen(
        currency,
      ),

      this.breaks.countOpenCritical(
        currency,
      ),

      this.suspense.sumOpen(
        currency,
      ),

      this.fx.sumOpenDestinationExposure(
        currency,
      ),
    ]);

    let status:
      | "GREEN"
      | "AMBER"
      | "RED" =
        "GREEN";

    if (
      safeguard.deltaMinor < 0n ||
      criticalBreaks > 0
    ) {
      status = "RED";
    } else if (
      openBreaks > 0 ||
      openSuspense > 0n ||
      openFx > 0n
    ) {
      status = "AMBER";
    }

    const evidence = {
      date:
        controlDate
          .toISOString()
          .slice(0, 10),

      currency,

      safeguard: {
        liability:
          safeguard.customerLiabilityMinor.toString(),
        asset:
          safeguard.safeguardingAssetMinor.toString(),
        delta:
          safeguard.deltaMinor.toString(),
      },

      treasury: {
        providerPayable:
          treasury.providerPayableMinor.toString(),
        providerReceivable:
          treasury.providerReceivableMinor.toString(),
      },

      openBreaks,
      criticalBreaks,

      openSuspense:
        openSuspense.toString(),

      openFx:
        openFx.toString(),

      status,
    };

    const evidenceHash =
      createHash("sha256")
        .update(
          JSON.stringify(
            evidence,
          ),
        )
        .digest("hex");

    return this.repo.upsert({
      controlDate,
      currency,

      customerLiabilityMinor:
        safeguard.customerLiabilityMinor,

      safeguardingAssetMinor:
        safeguard.safeguardingAssetMinor,

      safeguardingDeltaMinor:
        safeguard.deltaMinor,

      openBreakCount:
        openBreaks,

      criticalBreakCount:
        criticalBreaks,

      openSuspenseMinor:
        openSuspense,

      providerPayableMinor:
        treasury.providerPayableMinor,

      providerReceivableMinor:
        treasury.providerReceivableMinor,

      fxOpenPositionMinor:
        openFx,

      status,

      evidenceHash,
    });
  }
}

import {
  createHash,
} from "crypto";
import {
  Injectable,
} from "@nestjs/common";

@Injectable()
export class SettlementEvidenceService {
  constructor(
    private readonly repo:
      SettlementEvidenceRepository,
  ) {}

  async append(args: {
    eventType: string;
    referenceId: string;
    evidence:
      Record<string, unknown>;
  }) {
    const previous =
      await this.repo.latest();

    const canonical =
      JSON.stringify({
        eventType:
          args.eventType,
        referenceId:
          args.referenceId,
        evidence:
          args.evidence,
        previousHash:
          previous?.hash ??
          null,
      });

    const hash =
      createHash("sha256")
        .update(canonical)
        .digest("hex");

    return this.repo.insert({
      ...args,
      previousHash:
        previous?.hash,
      hash,
    });
  }
}

import { Injectable } from "@nestjs/common";

@Injectable()
export class LiquidityMonitorWorker {
  constructor(
    private readonly treasury:
      TreasuryPositionService,

    private readonly policy:
      LiquidityPolicyService,

    private readonly alerts:
      TreasuryAlertService,
  ) {}

  async run(
    currencies: string[],
  ) {
    for (const currency of currencies) {
      const position =
        await this.treasury.calculate(
          currency,
        );

      const result =
        await this.policy.evaluate({
          currency,
          availableMinor:
            position.availableLiquidityMinor,
        });

      if (
        result.state ===
          "CRITICAL" ||
        result.state ===
          "WARNING"
      ) {
        await this.alerts.raise({
          currency,
          state:
            result.state,
          position,
          recommendation:
            result,
        });
      }
    }
  }
}

@Injectable()
export class BreakEscalationWorker {
  constructor(
    private readonly breaks:
      ReconciliationBreakRepository,

    private readonly alerts:
      OperationsAlertService,
  ) {}

  async run() {
    const items =
      await this.breaks.listOpen();

    for (const item of items) {
      const ageHours =
        (
          Date.now() -
          item.openedAt.getTime()
        ) /
        3_600_000;

      if (
        item.severity ===
          "CRITICAL" ||
        ageHours >= 24
      ) {
        await this.alerts.raise({
          type:
            "RECONCILIATION_BREAK_ESCALATION",
          breakId:
            item.id,
          severity:
            item.severity,
          ageHours,
        });
      }
    }
  }
}

export class LinqaSendFinalMoneyMovementV5 {
  constructor(
    private readonly securityGate:
      SecureMoneyMovementGateV4,

    private readonly fxLiquidity:
      FxLiquidityService,

    private readonly settlement:
      SettlementInstructionService,

    private readonly evidence:
      SettlementEvidenceService,
  ) {}

  async execute(args: {
    transfer:
      SecureTransferView;

    sender:
      SenderContext;

    recipient:
      ResolvedRecipient;

    fundingSource:
      FundingSource;

    quote:
      PersistedQuote;

    installationId:
      string;

    deviceId:
      string;

    authorizationToken:
      string;
  }) {
    if (
      args.quote.sourceCurrency !==
      args.quote.destinationCurrency
    ) {
      await this.fxLiquidity.reserveForTransfer({
        transferId:
          args.transfer.id,

        sourceCurrency:
          args.quote.sourceCurrency,

        destinationCurrency:
          args.quote.destinationCurrency,

        sourceAmountMinor:
          args.quote.sourceAmountMinor,

        destinationAmountMinor:
          args.quote.destinationAmountMinor,

        customerRate:
          args.quote.customerRate,
      });
    }

    const result =
      await this.securityGate.execute(
        args,
      );

    await this.evidence.append({
      eventType:
        "MONEY_MOVEMENT_EXECUTED",
      referenceId:
        args.transfer.id,
      evidence: {
        transferClass:
          args.transfer.transferClass,
        sourceCurrency:
          args.quote.sourceCurrency,
        destinationCurrency:
          args.quote.destinationCurrency,
        sourceAmountMinor:
          args.quote.sourceAmountMinor.toString(),
        destinationAmountMinor:
          args.quote.destinationAmountMinor.toString(),
        resultStatus:
          result.status,
      },
    });

    return result;
  }
}

34. SECURITY + OPERATIONS INVARIANTS
================================================================================

1. Customer funds must not be booked as Linqa operating revenue.

2. Customer balances are liabilities.

3. Safeguarding/settlement assets are distinct from Linqa operating cash.

4. Internal transfers reallocate customer liabilities; they do not create
   revenue merely because the transfer is internal.

5. FX margin is recognized through an explicit revenue event and journal.

6. Reconciliation is evidence-driven and immutable.

7. External provider reports do not overwrite the internal ledger.

8. Mismatches create reconciliation breaks.

9. Reconciliation breaks are never deleted to make reports appear green.

10. Suspense usage requires a linked reconciliation break.

11. Suspense balances must age and escalate.

12. Treasury moves require scoped access and maker-checker approval.

13. Treasury maker cannot approve own action.

14. Settlement batches must be sealed before submission.

15. Batch checksum must be stored before provider submission.

16. Settlement instructions require idempotency.

17. Duplicate external settlement records are deduplicated.

18. Refunds/reversals require linked security/operations approval.

19. Chargebacks feed back into fraud-risk models.

20. Provider reserve/prefund status must be monitored.

21. Cross-currency transfers require liquidity/FX exposure control.

22. Open FX positions require policy limits.

23. Ledger and bank/provider settlement are independently reconciled.

24. Transfer COMPLETED does not imply provider settlement already occurred.
    Distinguish customer-facing transfer finality from treasury settlement.

25. End-of-day RED prevents silent GA-style "all green" reporting.

26. Every EOD result has a deterministic evidence hash.

27. Critical breaks and safeguarding shortfalls require immediate escalation.

28. No destructive correction of ledger or reconciliation evidence.

29. Historical capability/security/settlement evidence remains queryable.

30. Production rollout must remain corridor/provider/license gated.
