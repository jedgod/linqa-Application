# Linqa Conversation v2 — Indigo + Apricot

An additive conversation module for the existing Linqa application. Includes React web, React Native mobile, a shared encrypted-event client, Express routes, PostgreSQL tables, and unit tests. It is source code for integration, not a modification of your live repository. Existing authentication, device directory, cryptography, block/discovery policy, calling, notifications and attachment modules must be connected using the contracts below. No plaintext fallback is provided.

## Design and implemented features

- Violet, midnight and apricot themes. No green, doodle wallpaper or WhatsApp branding.
- Individual conversation screen, message history, text composer, clear relay acceptance and retry states.
- Encrypted topic lanes: All, Plans and Ideas. Messages retain their lane inside their encrypted payload.
- Encrypted decision boards: share 2–5 choices (mobile/web creation UI currently offers two), one vote per participant, latest vote wins, counts computed on clients.
- Local appearance and mute preferences, persisted through a device-storage adapter.
- Backend membership checks, canonical chat-policy checks, active-device checks, device-target validation, bounded ciphertext batches, pagination and transactionally persisted idempotency.
- Opening a registered person creates or reuses one direct conversation via a unique pair key.

These are distinctive combinations for Linqa; no claim is made that they are globally unprecedented.

The image is a design concept. The code does not implement timed quiet hours, a calendar-linked Plans card, photo attachments, vote-avatar displays, delivery/read checkmarks or custom icon artwork. Calls, voice, attachments, safety numbers and blocking invoke the supplied host handlers. The UI shows an integration notice when they are missing. The code labels relay acceptance accurately; it does not claim recipient delivery. Quiet is a per-conversation mute flag, not the image's timed schedule.

## Backend connection

1. Back up and inspect the actual live schema. Apply schema.sql in staging using your migration runner. Bind lc2_members.user_id to your actual canonical user UUID table with an FK after confirming its name. These lc2 tables deliberately do not overwrite existing tables. Do not blindly assign a migration number.
2. Import createConversationRouter into the existing authenticated Express server (the earlier Linqa setup used port 8088; use your current configured port).
3. Mount it after your host security middleware:

```js

 express, pool,

```

## Cryptographic bridge — mandatory

Use the existing Linqa NativeCore / DeviceIdentity / KeyPackageApi / E2eeMessageRepository implementation after reviewing its actual current interfaces. This pack does not implement a second cipher, ratchet or native key store.

```js
const existingE2eeConversationAdapter = {
 async encryptForDevices(payload,{conversationId,senderId,clientId}) {
   // 1. Resolve both users' active verified device key packages.
   // 2. Verify signatures and perform the existing authenticated protocol.
   // 3. Encrypt JSON payload separately for every eligible trusted device.
   // 4. Authenticate conversationId, senderId, clientId and device context as AAD.
   // 5. Return [{userId,deviceId,ciphertext:base64}, ...].
   throw new Error('Connect verified native E2EE send implementation');
 },
 async decryptAuthenticated(ciphertext,{conversationId,senderId,clientId}) {
   // Verify sender key/account binding, signatures, AAD and replay protections
   // using existing native crypto. Parse JSON only after verified decryption.
   throw new Error('Connect verified native E2EE receive implementation');
 }
};
```

Never base64-encode plaintext as a substitute for encryption. Schema/validation cannot prove ciphertext authenticity; the native adapter must. Encryption key lifecycle, forward secrecy, verified safety numbers, newly linked device history and key rotation remain responsibilities of the existing messaging protocol. Server can reject changed device sets with 409; refresh keys and retry using the same clientId. The UI retains stable IDs for retries but the in-memory pending queue is lost when the app restarts; wire the existing encrypted durable outbox before production.

## Existing relay/history mapping

This pack's lc2 transport is additive and does not migrate existing /v1/relay/envelopes or history automatically. Choose ONE authoritative storage path before deploying:

1. Prefer using existing relay infrastructure: implement the repo methods open, members, list, history and append against canonical conversation/relay tables, then inject that repository into createChatService in the router. Preserve transactionality and idempotency semantics.
2. Alternatively adopt lc2: write and test an explicit mapping of existing conversation IDs and ciphertext metadata. Never copy plaintext or silently split one conversation across two stores.

The HTTP client and server agree on /v2/conversations, /direct, /:id/events?after=cursor and /:id/events. Polling is sequential at 3 seconds; pagination drains 100-event pages. Switch to the existing authenticated WS wake-up flow later while keeping HTTP replay/cursor recovery. New linked devices do not receive historical envelopes unless the existing protocol supplies a secure history-transfer mechanism.

## Validation and release boundaries

Run `npm test` (or `node --test tests/*.test.mjs` without installing packages). Thirteen unit tests passed in the delivered version. They check nonmember denial, blocked initiation/send, self-chat rejection, duplicate/unauthorized/missing device targets, valid envelope batches, cursor validation, malformed ciphertext, vote replacement, invalid decision payloads, stable retry IDs, and authenticated-decryption failure. These are fake-repository unit tests; they do not certify PostgreSQL migrations, native encryption, physical devices, React rendering or production hosting.

Before live use, run your host typecheck/bundler, execute PostgreSQL migration/integration tests, verify concurrent direct opens and duplicate sends, and test sending/receiving between two physical devices. Also test revoked devices, block changes, offline restart recovery, stale key packages, notification mute, accessibility, keyboard/safe-area layout and the existing account-switch flow.

Authorization/device checks and the append transaction are separate calls here. To close revocation races in your live environment, make policy/device eligibility and append participate in your canonical transaction or versioned authorization mechanism; the current adapter contract alone does not guarantee atomic revocation. Do not call this pack production-ready until that integration and physical-device verification are complete.

The ZIP and Notepad text contain identical source content. This is an implementable integration module with explicit missing host adapters, not a claim that the current Linqa application has been changed or certified.

import {randomUUID} from 'node:crypto';
export function createPostgresRepository(pool) {
 async function transaction(fn) {
  const c = await pool.connect();
  try { await c.query('BEGIN'); const result = await fn(c); await c.query('COMMIT'); return result; }
  catch(e) { await c.query('ROLLBACK'); throw e; } finally { c.release(); }
 }
 return {
  async members(id) { const r=await pool.query('SELECT user_id FROM lc2_members WHERE conversation_id=$1',[id]); return r.rows.map(x=>x.user_id); },
  open(pair,members) { return transaction(async c=>{
   const r = await c.query('INSERT INTO lc2_conversations(id,pair_key) VALUES($1,$2) ON CONFLICT(pair_key) DO UPDATE SET pair_key=excluded.pair_key RETURNING id',[randomUUID(),pair]);
   const id=r.rows[0].id;
   for (const user of members) await c.query('INSERT INTO lc2_members VALUES($1,$2) ON CONFLICT DO NOTHING',[id,user]);
   return {id};
  }); },
  async list(user) {
   const r = await pool.query(`SELECT c.id,c.created_at,
    (SELECT m.user_id FROM lc2_members m WHERE m.conversation_id=c.id AND m.user_id<>$1 LIMIT 1) AS peer_id
    FROM lc2_conversations c JOIN lc2_members own ON own.conversation_id=c.id AND own.user_id=$1
    ORDER BY c.created_at DESC LIMIT 100`,[user]);
   return r.rows;
  },
  async history(id,actor,after) {
   const r = await pool.query(`SELECT e.seq::text,e.id,e.client_id,e.sender_id,e.created_at,x.ciphertext
    FROM lc2_events e JOIN lc2_envelopes x ON x.event_id=e.id
    WHERE e.conversation_id=$1 AND e.seq>$2::bigint AND x.user_id=$3 AND x.device_id=$4
    ORDER BY e.seq ASC LIMIT 100`,[id,after,actor.userId,actor.deviceId]);
   return {events:r.rows,cursor:r.rows.at(-1)?.seq ?? after,hasMore:r.rows.length===100};
  },
  append(id,actor,input,eventId) { return transaction(async c=>{
   const r = await c.query(`INSERT INTO lc2_events(id,conversation_id,sender_id,client_id) VALUES($1,$2,$3,$4)
    ON CONFLICT(conversation_id,sender_id,client_id) DO NOTHING RETURNING id,seq::text`,[eventId,id,actor.userId,input.clientId]);
   if (!r.rows.length) {
    const existing=await c.query('SELECT id,seq::text FROM lc2_events WHERE conversation_id=$1 AND sender_id=$2 AND client_id=$3',[id,actor.userId,input.clientId]);
    return {...existing.rows[0],duplicate:true};
   }
   for (const e of input.envelopes) await c.query('INSERT INTO lc2_envelopes VALUES($1,$2,$3,$4)',[eventId,e.userId,e.deviceId,e.ciphertext]);
   return {...r.rows[0],duplicate:false};
  }); }
 };
}

import {createChatService, requireValue, isUuid} from './service.mjs';
import {createPostgresRepository} from './postgres.mjs';
// Express passed by host; no second auth system or permissive dev fallback.
export function createConversationRouter({express,pool,authenticate,policy,devices,rateLimit,authorizeMutation}) {
 for (const [name,value] of Object.entries({authenticate,rateLimit,authorizeMutation})) if(typeof value!=='function') throw new Error(`Missing ${name} adapter`);
 if(typeof policy?.canChat!=='function' || typeof devices?.listForUsers!=='function' || typeof devices?.isActive!=='function') throw new Error('Missing policy/device adapters');
 const router=express.Router(); const service=createChatService({repo:createPostgresRepository(pool),policy,devices});
 const route=fn=>(req,res,next)=>Promise.resolve(fn(req,res)).catch(next);
 router.use(authenticate,rateLimit,express.json({limit:'2mb'}));
 router.use((req,res,next)=>Promise.resolve().then(async()=>{
  requireValue(isUuid(req.actor?.userId) && typeof req.actor?.deviceId==='string',401,'Authentication required');
  requireValue(await devices.isActive(req.actor.userId,req.actor.deviceId),401,'Device inactive');
 }).then(()=>next(),next));
 router.get('/',route(async(req,res)=>res.json({conversations:await service.list(req.actor)})));
 router.post('/direct',authorizeMutation,route(async(req,res)=>res.json(await service.open(req.actor,req.body?.peerId))));
 router.get('/:id/events',route(async(req,res)=>res.json(await service.history(req.actor,req.params.id,req.query.after??'0'))));
 router.post('/:id/events',authorizeMutation,route(async(req,res)=>res.status(202).json(await service.send(req.actor,req.params.id,req.body))));
 router.use((error,req,res,next)=>{
  // Do not log request bodies, ciphertext, keys or session tokens.
  res.status(error.status ?? 500).json({error:error.status?error.message:'Conversation service unavailable'});
 });
 return router;
}

BEGIN;
-- Separate names avoid overwriting existing Linqa chat tables. Bind user UUIDs
-- to your canonical account table after checking the actual live schema.
CREATE TABLE IF NOT EXISTS lc2_conversations (
 id uuid PRIMARY KEY, pair_key text UNIQUE NOT NULL, created_at timestamptz NOT NULL DEFAULT now()
);
CREATE TABLE IF NOT EXISTS lc2_members (
 conversation_id uuid REFERENCES lc2_conversations(id) ON DELETE CASCADE,
 user_id uuid NOT NULL, PRIMARY KEY(conversation_id,user_id)
);
CREATE TABLE IF NOT EXISTS lc2_events (
 seq bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
 id uuid UNIQUE NOT NULL, conversation_id uuid NOT NULL REFERENCES lc2_conversations(id),
 sender_id uuid NOT NULL, client_id uuid NOT NULL, created_at timestamptz NOT NULL DEFAULT now(),
 UNIQUE(conversation_id,sender_id,client_id),
 FOREIGN KEY(conversation_id,sender_id) REFERENCES lc2_members(conversation_id,user_id)
);
-- One ciphertext envelope per authorized device, including sender's devices.
-- User/device keys are opaque canonical IDs from the device directory adapter.
CREATE TABLE IF NOT EXISTS lc2_envelopes (
 event_id uuid REFERENCES lc2_events(id) ON DELETE CASCADE,
 user_id uuid NOT NULL, device_id text NOT NULL, ciphertext text NOT NULL,
 PRIMARY KEY(event_id,user_id,device_id)
);
CREATE INDEX IF NOT EXISTS lc2_events_history ON lc2_events(conversation_id,seq);
CREATE INDEX IF NOT EXISTS lc2_envelopes_recipient ON lc2_envelopes(user_id,device_id,event_id);
COMMIT;

import {randomUUID, createHash} from 'node:crypto';
export class ChatError extends Error {
 constructor(status, message) { super(message); this.status = status; }
}
export const requireValue = (ok, status, message) => { if (!ok) throw new ChatError(status, message); };
export const isUuid = value => typeof value === 'string' && /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i.test(value);
export function validateSend(input) {
 requireValue(input && isUuid(input.clientId),400,'Invalid clientId');
 requireValue(Array.isArray(input.envelopes) && input.envelopes.length > 0 && input.envelopes.length <= 32,400,'Invalid envelopes');
 const seen = new Set(); let total = 0;
 for (const e of input.envelopes) {
  requireValue(isUuid(e.userId) && typeof e.deviceId === 'string' && e.deviceId.length > 0 && e.deviceId.length <= 128,400,'Invalid device');
  requireValue(typeof e.ciphertext === 'string' && e.ciphertext.length >= 16 && e.ciphertext.length <= 131072 && /^(?:[A-Za-z0-9+/]{4})*(?:[A-Za-z0-9+/]{2}==|[A-Za-z0-9+/]{3}=)?$/.test(e.ciphertext),400,'Invalid ciphertext');
  const k = JSON.stringify([e.userId,e.deviceId]); requireValue(!seen.has(k),400,'Duplicate device'); seen.add(k); total += e.ciphertext.length;
 }
 requireValue(total <= 1048576,413,'Envelope batch too large');
 return input;
}
export function createChatService({repo, policy, devices}) {
 // policy must consult canonical accounts, blocks, chat requests and discovery.
 async function authorize(actor, id) {
  requireValue(isUuid(id),400,'Invalid conversation');
  const members = await repo.members(id);
  requireValue(members.includes(actor.userId),404,'Conversation unavailable');
  const other = members.find(x => x !== actor.userId);
  requireValue(other && await policy.canChat(actor.userId,other),403,'Chat is not permitted');
  return members;
 }
 return {
  async open(actor, peerId) {
   requireValue(isUuid(peerId) && peerId !== actor.userId,400,'Invalid recipient');
   requireValue(await policy.canChat(actor.userId,peerId),403,'Chat is not permitted');
   const pair = [actor.userId,peerId].sort();
   return repo.open(createHash('sha256').update(pair.join(':')).digest('hex'),pair);
  },
  async list(actor) { return repo.list(actor.userId); },
  async history(actor,id,after='0') {

export function projectEvents(events) {

 const boards = new Map(); const messages=[];

export function createConversationClient({request,crypto,actor,uuid}) {

import {useEffect,useRef,useState} from 'react';
import {projectEvents} from './engine.mjs';
export function useConversation(client,id) {
 const [events,setEvents]=useState([]),[error,setError]=useState(''),[pending,setPending]=useState([]),[sending,setSending]=useState(false);
 const state=useRef({id:null,cursor:'0'}), busy=useRef(false);
 useEffect(()=>{
  let cancelled=false, timer; const current={id,cursor:'0'}; state.current=current;
  setEvents([]);setPending([]);setError('');
  async function poll(){
   if(!id)return;
   try {
    let more=true;
    while(more && !cancelled) {
     const page=await client.page(id,current.cursor);
     if(cancelled)return;
     setEvents(old=>{const map=new Map(old.map(x=>[x.id,x]));for(const e of page.events)map.set(e.id,e);return [...map.values()];});
     setPending(old=>old.filter(d=>!page.events.some(e=>e.client_id===d.clientId && e.sender_id===client.actor.userId)));
     current.cursor=page.cursor; more=page.hasMore;
    }
    if(!cancelled)setError('');
   }catch(e){if(!cancelled)setError(e.message||'Unable to load messages');}
   finally{if(!cancelled)timer=setTimeout(poll,3000);}
  }
  poll();return()=>{cancelled=true;clearTimeout(timer);};
 },[client,id]);
 async function attempt(draft){
  if(busy.current || !id)return false;
  busy.current=true;setSending(true);const context=state.current;
  setPending(old=>[...old.filter(x=>x.clientId!==draft.clientId),{...draft,status:'sending'}]);
  try{
   await client.send(id,draft);
   if(state.current===context)setPending(old=>old.map(x=>x.clientId===draft.clientId?{...x,status:'accepted'}:x));
   return true;
  }catch(e){
   if(state.current===context){setError(e.message||'Send failed');setPending(old=>old.map(x=>x.clientId===draft.clientId?{...x,status:'failed'}:x));}
   return false;
  }finally{busy.current=false;setSending(false);}
 }
 return {messages:projectEvents(events),pending,error,sending,
  send:payload=>attempt(client.draft(payload)),retry:attempt};
}
