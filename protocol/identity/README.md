# Identity System

## Design Goals
- No mandatory phone number
- Support for:
  - Random opaque IDs
  - User-chosen usernames
  - Fully anonymous modes
- Secure, user-controlled recovery that does not permanently tie the account to a subpoena-able phone number or email
- Public Key Directory with transparency (auditable)

Users can optionally link a phone number or email for discoverability, but this is never required for registration or normal operation.

This is a core differentiator versus WhatsApp and Signal’s historical phone-number model.
