# Next Features Added

## Message Requests
Protects users from unknown senders and gives them Accept, Decline, Block, and Report controls.

## Status Viewer
Adds full-screen stories/status viewing, reactions, and encrypted private replies.

## Media
Turns the Media tab into a real gallery with filters, starred content, and storage awareness.

## Privacy Center
Makes device trust, sessions, encryption state, blocks, export, and deletion visible in one place.

## Device Alerts
Adds security alerts for newly linked devices, risky sessions, key changes, and revocation.

## Notifications
Adds quiet hours, mentions-only mode, and category-level controls.

## Accessibility
Adds font scaling, high contrast, reduced motion, and live captions.

## Storage
Adds usage visibility, large-file review, cache clearing, and automatic cleanup.

## AI Privacy
Lets users disable AI, keep it on-device, or explicitly enable confidential-cloud processing.
