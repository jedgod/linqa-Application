# Linqa New Mobile Features Pack

This pack upgrades the current Linqa mobile interface with:

- a complete Calls tab;
- scheduled audio/video calls;
- global search;
- Quick Create actions;
- status/stories;
- a Privacy Score card;
- advanced Settings navigation;
- PostgreSQL support for status and scheduled calls;
- API routes and client services.

The code follows React Native/Expo Router patterns and keeps security claims tied to runtime readiness.
