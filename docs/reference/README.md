# Reference library

These files are historical inputs and assessments, not executable app modules or evidence of current production readiness. They were moved here from the repository root without changing their contents.

- [Implementation notes](implementation-notes/): feature notebooks, compatibility manifests, and architecture references.
- [Designs](designs/): the three Calls TSX reference designs. Similarly named designs differ and have all been preserved.
- [Assessments](assessments/): previous Codex/Claude reviews and the August application diagnosis.

Original filenames and historical paths mentioned inside documents are retained for provenance. Live code remains under clients/, server/, core/, and the other existing source directories. Product references already grouped under Admin-Staff/, CountryLinqa™, LinkaSend-pageCode/, E2EE_Transport/, and Vault-Interface/ remain in place.

The [cleanup inventory](../maintenance/workspace-cleanup-2026-09-10.json) records each original path, destination, file size, and SHA-256 hash. Release manifests, formal certification evidence, source code, migrations, secrets, and installed dependencies were not cleanup targets.
