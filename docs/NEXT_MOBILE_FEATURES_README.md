# Linqa Next Mobile Features Addition Pack
Date: 2026-08-06

This pack extends the previous Linqa mobile feature pack (see
`docs/MOBILE_FEATURES_README.md`).

## New features added

1. **Message Requests** — unknown sender inbox; accept, decline, block, and report; preview without exposing read receipt; request-count badge.
2. **Status Viewer and Reactions** — full-screen status viewer; progress bars; reply and reaction support; mute status; privacy-aware viewer tracking.
3. **Media Gallery** — photos, videos, voice notes, files, and links; search, filters, starred items, and cleanup; conversation-scoped media browsing.
4. **Privacy Center** — privacy score; trusted devices; active sessions; encryption verification; blocked users; account deletion shortcut.
5. **Linked-Device Security Alerts** — new-device alert cards; verify or revoke device; last-seen and platform information; high-risk session warnings.
6. **Notification Controls** — quiet hours; priority contacts; mention-only mode; per-category notifications.
7. **Accessibility** — font scaling; high contrast; reduced motion; live captions; screen-reader optimization.
8. **Storage Management** — storage usage dashboard; cache cleanup; large-file detection; auto-download settings; expiring-media cleanup.
9. **AI Privacy Controls** — disabled, on-device, or confidential-cloud modes; per-feature AI permissions; clear data-processing disclosure.

See `docs/NEXT_MOBILE_FEATURES_APPLY_GUIDE.md` for what is and is not
actually wired up in this repository.
