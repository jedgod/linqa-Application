# Linqa Governance Principles

Linqa is designed as a privacy-first project. The following principles guide decision-making:

1. **No advertising or data selling**  
   The project will never monetize user data or show ads in the core product.

2. **Open source by default**  
   Clients, cryptographic core, and server components that affect security will be open source. Proprietary closed components that touch user content or keys are forbidden.

3. **Independent audits**  
   Regular third-party security audits of the protocol and implementations. Results published publicly.

4. **Minimal data retention**  
   Servers retain the absolute minimum data required to operate the service. Retention policies are transparent and independently verifiable where possible.

5. **User sovereignty**  
   Users control their identity and recovery material. No mandatory phone number or email.

6. **Nonprofit / foundation preference**  
   Long-term preference for a nonprofit or foundation structure similar to Signal, to align incentives with user privacy rather than shareholder value.

7. **Transparent roadmap and decisions**  
   Major protocol and product decisions are documented and open to community input.

These principles are non-negotiable for the project’s identity.
