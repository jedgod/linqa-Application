# Implementation Notes

To wire this into Linqa production:

- Replace Get Started console action with:
  router.push({ pathname: "/account/phone", params: { purpose: "REGISTRATION" } })

- Replace Log In action with:
  router.push({ pathname: "/account/phone", params: { purpose: "LOGIN" } })

- Keep authentication authority in the server.
- Do not treat the welcome screen as CountryLinqa authentication.
- CountryLinqa onboarding should follow authenticated account creation.
- For native Expo, replace HTML Tailwind classes with NativeWind equivalents or use this component in the web client.

Visual tuning targets from the provided image:
- 390x844 portrait reference
- near-full-height purple gradient
- white status icons
- centered pin logo
- large Linqa World title
- translucent tagline
- dotted white globe
- large white CTA
- white Log In action
- iOS home indicator

# Linqa World Welcome Screen

A Tailwind + shadcn-style React recreation of the supplied Linqa World welcome screen.

Includes:
- iPhone-style portrait shell
- purple/violet gradient
- status bar
- location-pin logo mark

- tagline
- dotted globe treatment
- Get Started CTA
- Log In link
- gesture/home indicator

Run:

import * as React from "react";
import { cn } from "../../lib/utils";

export interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: "primary" | "ghost";
}

export const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant = "primary", ...props }, ref) => {
    return (
      <button
        ref={ref}
        className={cn(
          "inline-flex items-center justify-center whitespace-nowrap rounded-2xl text-base font-semibold transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-white/70 disabled:pointer-events-none disabled:opacity-50",
          variant === "primary" &&
            "bg-white text-violet-700 shadow-[0_10px_35px_rgba(10,10,40,0.18)] hover:bg-white/95",
          variant === "ghost" &&
            "bg-transparent text-white hover:bg-white/10",
          className
        )}
        {...props}
      />
    );
  }
);

Button.displayName = "Button";

export type ClassValue =
  | string
  | false
  | null
  | undefined
  | Record<string, boolean>;

export function cn(...values: ClassValue[]) {
  const classes: string[] = [];

  for (const value of values) {
    if (!value) continue;

    if (typeof value === "string") {
      classes.push(value);
      continue;
    }

    for (const [className, enabled] of Object.entries(value)) {
      if (enabled) classes.push(className);
    }
  }

  return classes.join(" ");
}
