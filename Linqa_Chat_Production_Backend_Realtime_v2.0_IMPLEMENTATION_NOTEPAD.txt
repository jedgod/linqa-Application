LINQA CHAT — PRODUCTION BACKEND + REALTIME v2.0
Implementation notepad for Node.js / TypeScript / PostgreSQL / Redis
====================================================================

CONTINUATION CONTRACT
---------------------
This pack continues Linqa Chat Dynamic Additions v1.0. It implements the
authenticated services required by that mobile UI: inbox, direct/group chats,
messages, read state, presence, typing, scheduled calls, broadcasts, QR contact
exchange, and reliable delivery workers.

Reference stack (adapt names to an existing monorepo):
- Node.js 22, TypeScript 5, Fastify 5
- PostgreSQL 16+, node-postgres
- Redis 7+ for presence, rate limits, pub/sub, and queues
- jose for JWT verification; Argon2id for opaque secret hashes
- BullMQ for scheduled/retryable work
- Vitest + Testcontainers for integration tests

NON-NEGOTIABLE PRODUCTION RULES
-------------------------------
1. Authenticate HTTP and WebSocket connections before reading chat data.
2. Authorize every conversation operation with an active membership row.
3. Keep tenant/workspace scope in every query; never trust a client tenant ID.
4. Use client-generated UUID idempotency keys for message and broadcast writes.
5. Commit database state before publishing realtime events.
6. Persist durable events in chat_outbox; WebSocket delivery is an optimization.
7. Never claim E2EE unless the conversation capability and device session prove it.
8. Store timestamps as timestamptz in UTC; render in the user's timezone.
9. QR payloads contain short-lived opaque tokens, never raw private contact data.
10. Workers claim jobs with SKIP LOCKED and are safe to retry.

import { createRemoteJWKSet, jwtVerify } from 'jose';
import type { FastifyRequest } from 'fastify';

export type Principal = {
  userId: string; tenantId: string; deviceId: string; scopes: Set<string>;
};

const jwks = createRemoteJWKSet(new URL(process.env.AUTH_JWKS_URL!));

export async function authenticate(request: FastifyRequest): Promise<Principal> {
  const header = request.headers.authorization;
  if (!header?.startsWith('Bearer ')) throw request.server.httpErrors.unauthorized();
  const { payload } = await jwtVerify(header.slice(7), jwks, {
    issuer: process.env.AUTH_ISSUER,
    audience: 'linqa-chat-api',
    algorithms: ['RS256', 'ES256'],
  });
  if (!payload.sub || typeof payload.tid !== 'string' || typeof payload.did !== 'string')
    throw request.server.httpErrors.unauthorized('Invalid identity claims');
  return {
    userId: payload.sub,
    tenantId: payload.tid,
    deviceId: payload.did,
    scopes: new Set(typeof payload.scope === 'string' ? payload.scope.split(' ') : []),
  };
}

export function requireScope(p: Principal, scope: string) {
  if (!p.scopes.has(scope)) throw Object.assign(new Error('Forbidden'), { statusCode: 403 });
}

import { Pool, PoolClient } from 'pg';
export const pool = new Pool({ connectionString: process.env.DATABASE_URL, max: 20 });

export async function tx<T>(fn: (db: PoolClient) => Promise<T>): Promise<T> {
  const db = await pool.connect();
  try {
    await db.query('BEGIN');
    await db.query(`SET LOCAL statement_timeout = '5s'`);
    const value = await fn(db);
    await db.query('COMMIT');
    return value;
  } catch (error) {
    await db.query('ROLLBACK');
    throw error;
  } finally { db.release(); }
}

export async function assertMember(db: PoolClient, tenantId: string, userId: string, conversationId: string) {
  const result = await db.query(
    `SELECT role FROM conversation_member m JOIN conversation c ON c.id=m.conversation_id
     WHERE m.tenant_id=$1 AND m.user_id=$2 AND m.conversation_id=$3
       AND m.left_at IS NULL AND c.deleted_at IS NULL`,
    [tenantId, userId, conversationId],
  );
  if (!result.rowCount) throw Object.assign(new Error('Conversation not found'), { statusCode: 404 });
  return result.rows[0] as { role: 'owner'|'admin'|'member' };
}

import type { FastifyInstance } from 'fastify';
import { pool } from '../db.js';

export async function inboxRoutes(app: FastifyInstance) {
  app.get('/v1/chats/inbox', { preHandler: app.authenticate }, async (req) => {
    const p = req.principal;
    const filter = ['all','unread','groups','pinned'].includes(String(req.query.filter))
      ? String(req.query.filter) : 'all';
    const result = await pool.query(`
      WITH visible AS (
        SELECT c.*, m.pinned_at, m.muted_until, m.last_read_at
        FROM conversation c JOIN conversation_member m ON m.conversation_id=c.id
        WHERE c.tenant_id=$1 AND m.user_id=$2 AND m.left_at IS NULL AND c.deleted_at IS NULL
      ), summaries AS (
        SELECT v.id, v.kind, v.title, v.last_activity_at, v.pinned_at, v.muted_until,
          lm.kind preview_kind, COALESCE(lm.body_text, '') preview,
          (SELECT count(*)::int FROM chat_message x
           WHERE x.conversation_id=v.id AND x.deleted_at IS NULL
             AND x.sender_id<>$2 AND x.created_at>COALESCE(v.last_read_at,'epoch')) unread_count
        FROM visible v LEFT JOIN chat_message lm ON lm.id=v.last_message_id
      ) SELECT * FROM summaries
      WHERE ($3='all' OR ($3='unread' AND unread_count>0)
        OR ($3='groups' AND kind='group') OR ($3='pinned' AND pinned_at IS NOT NULL))
      ORDER BY (pinned_at IS NOT NULL) DESC, pinned_at DESC NULLS LAST, last_activity_at DESC
      LIMIT 100`, [p.tenantId, p.userId, filter]);
    const scheduled = await pool.query(`
      SELECT s.id, s.title, s.starts_at, s.call_provider_ref
      FROM scheduled_call s JOIN conversation_member m ON m.conversation_id=s.conversation_id
      WHERE s.tenant_id=$1 AND m.user_id=$2 AND m.left_at IS NULL
        AND s.state='scheduled' AND s.starts_at > now()-interval '10 minutes'
      ORDER BY s.starts_at LIMIT 1`, [p.tenantId, p.userId]);
    return {
      unreadTotal: result.rows.reduce((n, r) => n + r.unread_count, 0),
      scheduledCall: scheduled.rows[0] ? {
        eventId: scheduled.rows[0].id, title: scheduled.rows[0].title,
        startsAt: scheduled.rows[0].starts_at,
        joinable: scheduled.rows[0].starts_at <= new Date(Date.now()+10*60_000),
        callId: scheduled.rows[0].call_provider_ref ?? undefined,
      } : null,
      presence: await app.presence.forContacts(p.tenantId, p.userId),
      conversations: result.rows.map(app.presentChatSummary),
    };
  });
}

import type { FastifyInstance } from 'fastify';
import { tx, assertMember } from '../db.js';

export async function conversationRoutes(app: FastifyInstance) {
  app.post('/v1/chats/direct', { preHandler: app.authenticate }, async (req, reply) => {
    const p=req.principal; const { userId }=app.schemas.direct.parse(req.body);
    if (userId===p.userId) return reply.code(422).send({ code:'SELF_CHAT_NOT_ALLOWED' });
    const id=await tx(async db => {
      const target=await db.query(`SELECT 1 FROM app_user WHERE tenant_id=$1 AND id=$2 AND disabled_at IS NULL`,[p.tenantId,userId]);
      if(!target.rowCount) throw Object.assign(new Error('User not found'),{statusCode:404});
      const [low,high]=[p.userId,userId].sort();
      await db.query(`SELECT pg_advisory_xact_lock(hashtextextended($1,0))`,[`${p.tenantId}:${low}:${high}`]);
      const existing=await db.query(`SELECT conversation_id FROM direct_conversation_key WHERE tenant_id=$1 AND user_low=$2 AND user_high=$3`,[p.tenantId,low,high]);
      if(existing.rowCount) return existing.rows[0].conversation_id;
      const c=await db.query(`INSERT INTO conversation(tenant_id,kind,created_by) VALUES($1,'direct',$2) RETURNING id`,[p.tenantId,p.userId]);
      await db.query(`INSERT INTO direct_conversation_key VALUES($1,$2,$3,$4)`,[p.tenantId,low,high,c.rows[0].id]);
      await db.query(`INSERT INTO conversation_member(conversation_id,tenant_id,user_id,role) VALUES($1,$2,$3,'owner'),($1,$2,$4,'member')`,[c.rows[0].id,p.tenantId,p.userId,userId]);
      return c.rows[0].id;
    });
    return reply.code(201).send({conversationId:id});
  });

  app.post('/v1/chats/:conversationId/messages', { preHandler: app.authenticate }, async (req,reply) => {
    const p=req.principal, cid=String(req.params.conversationId);
    const input=app.schemas.message.parse(req.body);
    const message=await tx(async db => {
      await assertMember(db,p.tenantId,p.userId,cid);
      const c=await db.query(`SELECT e2ee_capable FROM conversation WHERE id=$1 AND tenant_id=$2 FOR UPDATE`,[cid,p.tenantId]);
      if(input.encrypted && !c.rows[0].e2ee_capable) throw Object.assign(new Error('E2EE unavailable'),{statusCode:409});
      const inserted=await db.query(`INSERT INTO chat_message
        (tenant_id,conversation_id,sender_id,client_message_id,kind,body_text,body_ciphertext,media)
        VALUES($1,$2,$3,$4,$5,$6,$7,$8)
        ON CONFLICT(tenant_id,sender_id,client_message_id) DO UPDATE SET client_message_id=EXCLUDED.client_message_id
        RETURNING id,conversation_id,sender_id,kind,created_at`,
        [p.tenantId,cid,p.userId,input.clientMessageId,input.kind,input.encrypted?null:input.text,
         input.encrypted?Buffer.from(input.ciphertext,'base64'):null,JSON.stringify(input.media??[])]);
      const m=inserted.rows[0];
      await db.query(`UPDATE conversation SET last_message_id=$1,last_activity_at=$2 WHERE id=$3`,[m.id,m.created_at,cid]);
      await db.query(`INSERT INTO chat_outbox(tenant_id,topic,aggregate_id,payload) VALUES($1,'message.created',$2,$3)`,[p.tenantId,cid,JSON.stringify(m)]);
      return m;
    });
    return reply.code(201).send(message);
  });

  app.post('/v1/chats/:conversationId/read', { preHandler: app.authenticate }, async req => {
    const p=req.principal,cid=String(req.params.conversationId);
    await tx(async db=>{
      await assertMember(db,p.tenantId,p.userId,cid);
      const last=await db.query(`SELECT id,created_at FROM chat_message WHERE conversation_id=$1 AND deleted_at IS NULL ORDER BY created_at DESC,id DESC LIMIT 1`,[cid]);
      await db.query(`UPDATE conversation_member SET last_read_message_id=$1,last_read_at=COALESCE($2,last_read_at) WHERE conversation_id=$3 AND user_id=$4`,[last.rows[0]?.id,last.rows[0]?.created_at,cid,p.userId]);
      await db.query(`INSERT INTO chat_outbox(tenant_id,topic,aggregate_id,payload) VALUES($1,'conversation.read',$2,$3)`,[p.tenantId,cid,JSON.stringify({conversationId:cid,userId:p.userId,messageId:last.rows[0]?.id})]);
    });
    return {ok:true};
  });
}

import type { FastifyInstance } from 'fastify';
import { WebSocket } from 'ws';

type ClientEvent =
 | {type:'subscribe';conversationIds:string[]}
 | {type:'typing.start'|'typing.stop';conversationId:string}
 | {type:'presence.heartbeat'};

export async function realtimeGateway(app: FastifyInstance) {
  app.get('/v1/realtime', {websocket:true}, async (socket,req) => {
    let principal;
    try { principal=await app.authenticateWebSocket(req); }
    catch { socket.close(4401,'Unauthorized'); return; }
    const connectionId=crypto.randomUUID();
    await app.presence.connect(principal,connectionId);
    const unsubscribe=await app.realtime.attach(principal,connectionId,socket);
    socket.on('message',async raw=>{
      if(raw.byteLength>16_384) return socket.close(4400,'Frame too large');
      let event:ClientEvent;
      try { event=app.schemas.clientEvent.parse(JSON.parse(raw.toString())); }
      catch { return socket.send(JSON.stringify({type:'error',code:'INVALID_EVENT'})); }
      try {
        if(event.type==='subscribe') {
          if(event.conversationIds.length>100) throw Object.assign(new Error(),{statusCode:422});
          const allowed=await app.memberships.filterAllowed(principal,event.conversationIds);
          await app.realtime.subscribe(connectionId,allowed);
        } else if(event.type==='presence.heartbeat') await app.presence.heartbeat(principal,connectionId);
        else {
          await app.rateLimit.consume(`typing:${principal.userId}`,20,10);
          await app.memberships.assert(principal,event.conversationId);
          await app.realtime.ephemeral(event.type,{conversationId:event.conversationId,userId:principal.userId},5);
        }
      } catch { socket.send(JSON.stringify({type:'error',code:'EVENT_REJECTED'})); }
    });
    const ping=setInterval(()=>{if(socket.readyState===WebSocket.OPEN) socket.ping();},25_000);
    socket.once('close',async()=>{clearInterval(ping);await unsubscribe();await app.presence.disconnect(principal,connectionId);});
  });
}

SERVER EVENT ENVELOPE
---------------------
All durable events use:
{ "type": "message.created", "eventId": 8812, "occurredAt": "...",
  "conversationId": "...", "payload": { ... } }
Clients store the greatest eventId, ignore duplicates, and reconnect with
`?afterEventId=8812`. If retention has expired, server sends `sync.required`
and the client refreshes `/v1/chats/inbox` plus open-message pages.

export async function schedulingRoutes(app) {
  app.post('/v1/calls/scheduled',{preHandler:app.authenticate},async(req,reply)=>{
    const p=req.principal,input=app.schemas.scheduleCall.parse(req.body);
    if(new Date(input.startsAt).getTime()<Date.now()+60_000) return reply.code(422).send({code:'START_TOO_SOON'});
    const row=await tx(async db=>{
      await assertMember(db,p.tenantId,p.userId,input.conversationId);
      const r=await db.query(`INSERT INTO scheduled_call(tenant_id,conversation_id,created_by,title,kind,starts_at,ends_at)
        VALUES($1,$2,$3,$4,$5,$6,$7) RETURNING *`,[p.tenantId,input.conversationId,p.userId,input.title,input.kind,input.startsAt,input.endsAt]);
      await db.query(`INSERT INTO delivery_job(tenant_id,job_type,dedupe_key,payload,run_at)
        VALUES($1,'call.reminder',$2,$3,$4) ON CONFLICT(dedupe_key) DO NOTHING`,[p.tenantId,`call:${r.rows[0].id}:reminder`,JSON.stringify({callId:r.rows[0].id}),new Date(new Date(input.startsAt).getTime()-10*60_000)]);
      return r.rows[0];
    });
    return reply.code(201).send(row);
  });

  app.post('/v1/calls/scheduled/:eventId/join',{preHandler:app.authenticate},async(req,reply)=>{
    const p=req.principal,id=String(req.params.eventId);
    const row=await pool.query(`SELECT s.* FROM scheduled_call s JOIN conversation_member m ON m.conversation_id=s.conversation_id
      WHERE s.id=$1 AND s.tenant_id=$2 AND m.user_id=$3 AND m.left_at IS NULL`,[id,p.tenantId,p.userId]);
    const event=row.rows[0];
    if(!event) return reply.code(404).send({code:'EVENT_NOT_FOUND'});
    if(event.state!=='scheduled'||Date.now()<new Date(event.starts_at).getTime()-10*60_000) return reply.code(409).send({code:'NOT_JOINABLE'});
    const call=await app.calls.getOrCreate(event);
    return {callId:call.id,joinToken:await app.calls.issueJoinToken(call,p,300)};
  });
}

export async function broadcastRoutes(app) {
  app.post('/v1/broadcasts',{preHandler:app.authenticate},async(req,reply)=>{
    const p=req.principal; requireScope(p,'chat:broadcast');
    const input=app.schemas.broadcast.parse(req.body);
    if(input.recipientIds.length>5000) return reply.code(422).send({code:'RECIPIENT_LIMIT'});
    const campaign=await tx(async db=>{
      const allowed=await db.query(`SELECT contact_user_id FROM contact WHERE tenant_id=$1 AND owner_user_id=$2 AND contact_user_id=ANY($3::uuid[])`,[p.tenantId,p.userId,input.recipientIds]);
      if(allowed.rowCount!==new Set(input.recipientIds).size) throw Object.assign(new Error('Invalid recipient'),{statusCode:422});
      const c=await db.query(`INSERT INTO broadcast_campaign(tenant_id,created_by,title,message_body,scheduled_at,state,client_request_id)
        VALUES($1,$2,$3,$4,$5,$6,$7) ON CONFLICT(tenant_id,created_by,client_request_id)
        DO UPDATE SET client_request_id=EXCLUDED.client_request_id RETURNING *`,[p.tenantId,p.userId,input.title,input.messageBody,input.scheduledAt,input.scheduledAt?'scheduled':'processing',input.clientRequestId]);
      for(const r of allowed.rows) await db.query(`INSERT INTO broadcast_recipient(campaign_id,recipient_id) VALUES($1,$2) ON CONFLICT DO NOTHING`,[c.rows[0].id,r.contact_user_id]);
      await db.query(`INSERT INTO delivery_job(tenant_id,job_type,dedupe_key,payload,run_at) VALUES($1,'broadcast.deliver',$2,$3,COALESCE($4,now())) ON CONFLICT DO NOTHING`,[p.tenantId,`broadcast:${c.rows[0].id}`,JSON.stringify({campaignId:c.rows[0].id}),input.scheduledAt]);
      return c.rows[0];
    });
    return reply.code(202).send({campaignId:campaign.id,state:campaign.state});
  });
}

import { randomBytes,createHash } from 'node:crypto';
const hash=(token:string)=>createHash('sha256').update(token).digest();

export async function qrContactRoutes(app) {
  app.post('/v1/contacts/qr',{preHandler:app.authenticate},async(req,reply)=>{
    const p=req.principal,token=randomBytes(32).toString('base64url');
    const row=await pool.query(`INSERT INTO contact_qr_token(tenant_id,owner_user_id,token_hash,expires_at)
      VALUES($1,$2,$3,now()+interval '5 minutes') RETURNING id,expires_at`,[p.tenantId,p.userId,hash(token)]);
    return reply.code(201).send({qrPayload:`linqa://contact?v=1&t=${token}`,expiresAt:row.rows[0].expires_at});
  });

  app.post('/v1/contacts/qr/redeem',{preHandler:app.authenticate},async(req,reply)=>{
    const p=req.principal,{token}=app.schemas.redeemQr.parse(req.body);
    const owner=await tx(async db=>{
      const found=await db.query(`SELECT * FROM contact_qr_token WHERE token_hash=$1 FOR UPDATE`,[hash(token)]);
      const q=found.rows[0];
      if(!q||q.tenant_id!==p.tenantId||q.revoked_at||q.use_count>=q.max_uses||new Date(q.expires_at)<=new Date())
        throw Object.assign(new Error('QR invalid or expired'),{statusCode:410});
      if(q.owner_user_id===p.userId) throw Object.assign(new Error('Own QR'),{statusCode:422});
      await db.query(`UPDATE contact_qr_token SET use_count=use_count+1 WHERE id=$1`,[q.id]);
      await db.query(`INSERT INTO contact(tenant_id,owner_user_id,contact_user_id,created_via)
        VALUES($1,$2,$3,'qr'),($1,$3,$2,'qr') ON CONFLICT DO NOTHING`,[p.tenantId,p.userId,q.owner_user_id]);
      return q.owner_user_id;
    });
    return reply.code(201).send({contactUserId:owner});
  });
}

const MAX_ATTEMPTS=8;
export async function claimJobs(db,limit=50) {
  return (await db.query(`WITH due AS (
    SELECT id FROM delivery_job WHERE (state='pending' OR (state='leased' AND leased_until<now())) AND run_at<=now()
    ORDER BY run_at,id FOR UPDATE SKIP LOCKED LIMIT $1)
    UPDATE delivery_job j SET state='leased',leased_until=now()+interval '60 seconds',attempts=attempts+1
    FROM due WHERE j.id=due.id RETURNING j.*`,[limit])).rows;
}

export async function runDeliveryBatch(app) {
  const jobs=await tx(db=>claimJobs(db));
  for(const job of jobs) {
    try {
      if(job.job_type==='broadcast.deliver') await app.broadcasts.deliver(job.payload.campaignId);
      else if(job.job_type==='call.reminder') await app.calls.sendReminder(job.payload.callId);
      else if(job.job_type==='push.message') await app.push.deliver(job.payload);
      await pool.query(`UPDATE delivery_job SET state='completed',leased_until=NULL WHERE id=$1`,[job.id]);
    } catch(error) {
      const retry=job.attempts<MAX_ATTEMPTS && app.errors.isRetryable(error);
      const delay=Math.min(3600,Math.pow(2,job.attempts)*5)+Math.random()*5;
      await pool.query(`UPDATE delivery_job SET state=$2,run_at=now()+($3||' seconds')::interval,leased_until=NULL,last_error_code=$4 WHERE id=$1`,
        [job.id,retry?'pending':'dead',delay,app.errors.safeCode(error)]);
    }
  }
}

OUTBOX RELAY
------------
Claim unpublished chat_outbox rows with `FOR UPDATE SKIP LOCKED`, publish each
event to Redis topic `tenant:{tenantId}:chat`, then set published_at. Consumers
deduplicate by outbox id. A periodic reconciliation republishes rows whose
published_at is null; no database transaction is held during network I/O.

SECURITY CHECKLIST (enforced in code and infrastructure)
--------------------------------------------------------
- JWT: exact issuer/audience, algorithm allowlist, <=15 minute access tokens.
- WebSocket: bearer token in Sec-WebSocket-Protocol or one-time ticket; never URL logs.
- Authorization: tenant + active membership predicates on every resource query.
- Validation: strict Zod schemas; reject unknown keys; 4 KB text and 16 KB WS limits.
- Rate limits: user+device+IP buckets: inbox 120/min, messages 60/min,
  QR create 10/hour, QR redeem 30/hour, broadcasts 10/day.
- CSRF: bearer-only mobile API; if cookies are added, SameSite plus CSRF token.
- Secrets: managed secret store, quarterly rotation, no secrets in app bundles.
- Encryption: TLS 1.3; encrypted volumes/backups; push tokens field-encrypted.
- E2EE: server stores ciphertext only; keys remain on devices; safety-number changes
  invalidate `e2eeVerified` until users re-verify.
- Media: signed uploads, MIME sniffing, malware scan, byte/pixel/duration limits.
- Logging: redact authorization, QR token, join token, message body, and push token.
- Audit: append security-relevant actions; restrict readers; retain per policy.
- Abuse: block/report controls, recipient caps, broadcast permission, moderation queue.
- Database: least-privilege runtime role; migration role separate; PITR backups tested.
- Supply chain: lockfiles, signature/provenance checks, SCA and container scanning.
- Availability: request deadlines, bounded pools, circuit breakers, graceful shutdown.

Recommended PostgreSQL defense-in-depth: enable RLS on tenant tables and set
`SET LOCAL app.tenant_id` and `app.user_id` inside every transaction. Application
predicates remain mandatory; RLS is a second barrier, not a replacement.
