# CountryLinqa™ Discovery Settings — Production Finish Pack

This pack is the next layer after the 1–6 UI set.

Adds:
1. Separate "I discover" and "Who discovers me" policy.
2. Searchable country selector with hard entitlement limits.
3. Region and Worldwide server enforcement.
4. Privacy/location visibility separated from verified-country identity.
5. Pause Discovery / invisible mode.
6. Unsaved-change protection and optimistic-save rollback.
7. Server-authoritative preferences API and PostgreSQL migration.
8. Entitlement enforcement middleware.
9. Audit/outbox events.
10. Abuse/risk hooks for suspicious country-scope changes.
11. Accessibility and reduced-motion support.
12. Analytics events without leaking precise location.
13. Unit/API/E2E test templates.
14. Production release checklist.

Apply this pack by adapting repository imports/table names to the live Linqa schema.
