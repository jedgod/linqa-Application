# What this makes CountryLinqa

The completed design has four independent layers:

1. VERIFIED IDENTITY COUNTRY
   Evidence-derived, security controlled, not editable from Discovery Settings.

2. OUTBOUND DISCOVERY
   Controls where the user wants to find new people/content.

3. INBOUND DISCOVERABILITY
   Controls which geographic audiences can discover the user.

4. PROFILE LOCATION VISIBILITY
   Controls whether country/state/city labels are displayed after eligibility.

This separation is the key production correction. It avoids treating "country",
"where I browse", "who can find me", and "what location I display" as one setting.
