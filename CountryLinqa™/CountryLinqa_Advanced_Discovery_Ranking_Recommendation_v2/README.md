# CountryLinqa™ Advanced Discovery + Ranking / Recommendation Engine v2

Implements the next layer after the CountryLinqa Discovery Engine Integration pack:

- Personalized candidate ranking
- Interests, language, profession, verified-only and online filters
- Saved searches
- Opaque cursor pagination
- Redis cache architecture + policy-version invalidation
- Abuse resistance / scraping controls
- Privacy-preserving telemetry
- Explainable recommendation reasons
- Ranking diversity controls
- Two-country physical-device certification
- Release gates

IMPORTANT:
This is a production integration pack, not a claim that physical certification has been executed.
Device/country certification must be run against real devices, real accounts and the deployed Git SHA.
