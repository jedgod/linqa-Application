====================================================================================================================
LINQA UI ALL-PAGES PACK

1. Copy app/ and src/ into clients/mobile.
2. Enable Expo Router.
3. npm install libphonenumber-js @expo/vector-icons
4. Replace demoAccounts with GET /v6/installations/:installationId/accounts.
5. Replace UI handlers with PhoneFirstIdentityClient + AccountRuntimeManager.
6. Registration: Welcome -> Detect Country -> Phone -> Carrier Check -> Phone OTP -> Recovery Email -> Email OTP -> Activate -> Home.
7. Add Account uses same identity flow and must fresh-authenticate the target account.
8. Avatar is primary account-switch entry; Settings > Account is secondary management entry.
9. At three accounts, disable Add Account and also handle server ACCOUNT_LIMIT_REACHED.
10. Test at 390x844, 393x852, and 430x932 portrait viewports.

# Linqa UI — Full Phone-First + Multi-Account Portrait Flow

React Native/Expo Router UI pack representing the complete storyboard: Welcome, country detection, phone entry, carrier check, phone OTP, recovery email, email OTP, activation, Personal/Business/Research homes, account switching, add account, manage accounts, 3-account maximum, notification account routing, account settings, and remove account.

Production services are injected behind UI handlers; demo state is only for visual flow.

# Production Wiring Map

Create Account -> /v6/registration/start
Phone entry -> /v6/registration/:flowId/phone
Carrier check -> server line-intelligence decision
Phone OTP -> /v6/registration/:flowId/phone/verify
Recovery email -> /v6/registration/:flowId/recovery-email
Email OTP -> /v6/registration/:flowId/recovery-email/verify
Activate -> /v6/registration/:flowId/activate
List accounts -> GET /v6/installations/:installationId/accounts
Switch -> POST /v6/installations/:installationId/switch

On secure switch: lock previous crypto namespace, close previous encrypted DB, save target session, activate target crypto namespace, open target DB, activate target push context, then reload Home/Chats/Vault.

Notification taps must activate notification.accountUserId before opening the notification route.

Remove Account means remove local installation membership; Delete Account is a separate server privacy/account deletion workflow.

import React,{createContext,useContext,useMemo,useState} from "react";import {accounts as demo} from "../data/demoAccounts";
const X=createContext<any>(null);
export function AccountProvider({children}:{children:React.ReactNode}){const [accounts,setAccounts]=useState<any[]>([demo[0]]);const [active,setActive]=useState('personal');const value=useMemo(()=>({accounts,active,canAdd:accounts.length<3,add:(a:any)=>setAccounts(v=>v.length>=3||v.some(x=>x.id===a.id)?v:[...v,a]),remove:(id:string)=>setAccounts(v=>v.filter(x=>x.id!==id)),switchTo:(id:string)=>setActive(id)}),[accounts,active]);return <X.Provider value={value}>{children}</X.Provider>}
export const useAccounts=()=>{const v=useContext(X);if(!v)throw new Error('AccountProvider missing');return v};
