LINQA - USB ANDROID LAUNCH

Windows shortcut: double-click launch-linqa.cmd in the repository root.
The launcher starts the API with source watching enabled.

From the repository root:
    node scripts/start-mobile-usb.mjs

Or from clients/mobile:
    npm run launch:usb

Connect and authorize the phone over USB. The launcher starts the Linqa API,
starts Metro, restores USB forwarding, and opens com.linqa.mobile.
Re-run after disconnecting or rebooting the phone.

Phone API: http://127.0.0.1:8080
Computer API: http://127.0.0.1:8088 (8089 if occupied)
Metro: http://127.0.0.1:8081
Logs: .runtime/mobile-launch/

Do not use 10.0.2.2 on a physical phone. That alias is for the emulator.
Computer port 8080 may belong to Apache; the launcher preserves that service.

For a debug app loading an old embedded bundle, use the React Native developer
menu: Change Bundle Location -> localhost:8081 -> Apply Changes -> Reload.

Setup, dependency and build instructions: clients/mobile/README.md
The Kotlin client in clients/android (com.linqa.app) is a separate app.
